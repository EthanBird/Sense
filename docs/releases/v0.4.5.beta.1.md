# Sense v0.4.5.beta.1 预发布说明

## 版本

- Tag：`v0.4.5.beta.1`
- Android：`versionCode 22`，`versionName 0.4.5.beta.1`
- 平台：Android 10+，`minSdk 29`，`targetSdk 36`
- 发布性质：GitHub Pre-release

## 键盘架构

- 将键盘尺寸策略、主键区布局、图标绘制、颜色与滚动投影从
  `SenseKeyboardView` 中拆分为独立模块；
- 新增 Android-free `CandidatePanel`，集中管理候选发布、测量缓存、分页、
  投影命中和横向拖动；
- `SenseKeyboardView` 只保留 Canvas、MotionEvent 与帧调度平台边界，为后续
  自定义键盘高度和九宫格布局保留稳定扩展面；
- 候选栏加入场景键缓存、primitive 宽度路径及等值 relayout 复用，减少大候选批次
  的对象分配与重复扫描；
- 修复异步 pending → ready 时新候选继承旧候选偏移或 settle 动画的问题；
- 展开、折叠和页边界操作停止无效动画与重绘，同时保持精确 `sourceIndex` 命中。

## 稳定性

- Android/Linux 继续执行目录 fsync；Windows NIO 不支持目录句柄 force 时保留已经
  完成的文件 fsync 与原子 rename，确保 JVM 测试和本地恢复流程一致；
- `SenseKeyboardSurface` 统一负责键盘高度计算，IME Service 与测试 Activity 不再
  各自复制横竖屏高度逻辑；
- 既有 Skills、动态极光、Agent 工具、完整 Journal、本地记忆与普通输入功能继续保留。

## 固定发布签名

本版本建立 `Sense Release v1` 固定签名，GitHub Release 从 `app-release.apk`
发布，不再使用 hosted runner 临时生成的 benchmark/debug 证书。

- 证书：[`sense-release-v1-cert.pem`](https://github.com/EthanBird/Sense/blob/v0.4.5.beta.1/docs/releases/signing/sense-release-v1-cert.pem)
- SHA-256：
  `76db888ff42b04d52d4d19a573fe8f8df2fa3af0ab36bd6a08c6f70a8aace984`
- 算法：RSA-4096 / SHA256withRSA
- 私钥材料仅存于本机仓库外的固定 PKCS12 与备份，仓库只保留公开证书和指纹

从 `v0.4.5.beta.1` 开始，后续 GitHub Release 使用同一证书并递增
`versionCode`，形成可持续覆盖升级链。此前发布资产使用临时 debug signer，
不属于这条固定签名升级链。

## 验证

- GitHub Actions 工作流已移除，`tools/local_release.ps1` 在本机统一执行全部门禁、
  固定签名构建、发布上传与回下载复核；
- Gradle 全量 JVM/Android 单元测试；
- Android Lint；
- debug、benchmark、release 与 AndroidTest APK 构建；
- release APK v3 签名、唯一 signer 指纹、zipalign、包名、版本、SDK、
  Manifest 权限白名单与生产资产哈希；
- release-plan、Manifest typed value 与 Maven 代理测试。

本轮按发布要求跳过真机 UI 回归；对应 AndroidTest APK 与候选滚动后精确点击用例
仍由构建和后续设备门禁保留。
