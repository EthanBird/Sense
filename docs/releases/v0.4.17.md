# Sense v0.4.17 — Agent 记忆浏览与设置页改版

Android 正式版，`versionCode 49`，沿用自 v0.4.7 延续的正式签名配置。

## Agent 记忆

- 新增无关键词浏览：“列出记忆”“看看记住了什么”可以直接调用工具，不必先猜关键词。
- 支持原始会话、跨会话经历事件和 API 调用记录，分页返回并可继续查看。
- 列表提取正文与摘要，减少协议字段、低层流式记录和重复记忆工具回显；原始保存内容保持完整。
- 更新 Agent 提示词，区分零匹配、还有后续页、存储未连接和读取失败，避免将关键词没命中解释为没有历史。
- 对工具结果按 JSON 转义长度分配预算，减少长结果被截成不完整 JSON 的情况。

## 设置与 Skills

- 底部导航调整为首页 / Agent / Skills / 更多。
- Agent 页集中展示模型、工具、记忆说明与远程信道入口；对话、终端和浏览器仍在输入法前端。
- Skills 改为技能库与独立编辑视图，增加搜索、筛选、草稿标记和键位摘要。
- 编辑页优先展示名称、描述和指令，高级选项与键盘绑定折叠；返回技能库保留草稿，显式放弃需要确认。
- 修复 API 动作开关保存失败后失去重试响应的问题。

## 范围与发布方式

本轮按用户要求只进行正式签名打包，不执行额外测试、lint、模拟器或真机验证。
记忆浏览返回有界摘录而非全量导出；多来源按各自记录顺序列出，不宣称全局时间排序。
远程信道保持原有接收式能力，未新增 Telegram 用户客户端或通用 API 创建器。
本次不更新 Sense Mic 桌面客户端，也不加入尚在研究的 Android 词级 LM 原型。

下载 `Sense-v0.4.17.apk` 覆盖安装，无需清空既有应用数据。
