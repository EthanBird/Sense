# Sense v0.4.5.beta 预发布说明

## 版本

- Tag：`v0.4.5.beta`
- Android：`versionCode 21`，`versionName 0.4.5.beta`
- 平台：Android 10+，`targetSdk 36`
- 发布性质：GitHub Pre-release

## 预览范围

本预发布基于正式版 v0.4.5，继续验证键盘集成 Skills、动态极光与 Agent Skills ABI：

- 长按已绑定按键后向四个方向滑动选择 Skill，再次选择可取消激活；
- 激活键使用独立子层绘制动态极光，不改变键盘高度，也不带动整张键盘重绘；
- 设置页支持创建、修改、绑定、解绑和恢复 Skill 历史版本；
- Agent 可按需调用分页 `skill_read`，并在用户启用后调用 `skill_manage`；
- 单次 Agent run 冻结准确的 catalog generation 与 Skill revision；
- v0.4.4 的联网工具、完整 Agent Journal 与本地记忆检索继续保留。

## 验证边界

本地与 GitHub 流水线会重新执行版本契约、JVM 测试、Lint、Android 构建、APK 元数据、
签名、zipalign、权限 typed value 和生产资产哈希门禁。

发布前本地验证已完成：

- 版本感知 release-plan 测试 26 项通过；
- Gradle 全量门禁 513 个任务成功，覆盖 JVM/Android 单元测试、Android test APK、
  四个 Lint、debug/benchmark APK 与 benchmark 模块；
- benchmark APK 已验证包名、`versionCode 21`、`versionName 0.4.5.beta`、
  `minSdk 29`、`targetSdk 36`、v2 签名、4K/16K zipalign 与 manifest 权限保护。

真实 Provider Key 探针、固定物理设备 Aurora 绝对性能门禁，以及长期系统 IME 宿主交错
