# Sense v0.4.16-rc.7 — 减少拼音组词中的临时分配

- Android `versionCode 47`，沿用原正式证书，支持同签名覆盖升级。
- GitHub Pre-release；保留 rc.6 及旧附件，不替换 v0.4.15 最新稳定版。
- 仅发布 Android APK，Sense Mic 桌面客户端不变。

## 这次更新

拼音组词搜索不再为每个中间路径反复拼接完整首字母字符串，而是保留词边与父路径，
等候选真正导出时再生成字符串。纠错所需的长度信息仍随路径精确保留。
词库、语言模型、评分、候选排序、搜索预算、个人词库格式和 UI 布局保持不变。

保留 rc.6 的词间搭配候选保留修复，以及此前的个人词学习与重启恢复、联想生命周期、
显式拼音分词、换位纠错和码表查找优化。未纳入性能门槛未通过的 E47 缓存或研究模型。

## 验证结果与范围

- E48：973 项核心/服务/UI 单元测试、36 项评测工具检查通过。
- 49 项专用模拟器功能检查通过，覆盖学习、重启、隐私、上下文、纠错、分词、联想和外部编辑框。
- 3,083 个逐键输入状态的完整候选结果及语言模型调用保持一致。
- 主机 JVM 解码线程分配计数估计降低 **6.38%**；不是手机常驻内存或耗电测量。
- 同轮固定模拟器 A-B-B-A：确认上屏延迟中位数 **146→146 ms**、P95 **315→292 ms**、最大值 **339→311 ms**；64 次确认、8 次续打均正确。

三个查询的中位数仍变慢，两个查询的 P95 变差，逐项结果保留在 E48 报告中。
本版不宣称所有场景提速、全面低于 100 ms 或准确率提高；自然同音句和长句选词仍有误判。

上述 Android 数据来自 E48 固定 Debug APK，非本正式签名 APK 的重新实测，也不代表所有手机。
发布阶段重新构建并检查正式签名、包身份、资产、Release lint 和模块边界，
核对发布源码与已测版本一致。具体范围见 `BUILD-INFO.json`；没有操作实体手机。

## 升级

覆盖安装保留数据，沿用 SQLite v4 个人词库及既有迁移逻辑。回退前先导出个人词条和配置。
APK 校验值见 `SHA256SUMS.txt`。更广的设备/UI 生命周期覆盖和语义选词质量仍在开发中。
