# Sense v0.4.16-rc.3 — 冷加载输入响应修复

- Android `versionCode 43`，沿用原正式发布证书，支持同签名版本覆盖升级。
- GitHub Pre-release；rc.1 / rc.2 原附件保留，v0.4.15 仍是最新稳定版。
- 仅更新 Android APK，不重新发布 Sense Mic 桌面客户端。

## 本次修复

词库刚开始加载或候选计算较慢时，如果还没有排入下一段输入，**回车立即确认当前原文，
退格立即编辑当前拼音**，不再等到“候选较慢”提示出现才响应。
已经接着输入后续词时，继续按原有队列顺序处理，避免前后两段串词、漏字或重复上屏。

保留 rc.2 的同音词上下文记忆、个人词重启恢复、隐私隔离和纠错查询内复用。
词库、离线语言模型及个人词数据库格式保持不变。

## 验证与范围

- E30 通过受控延迟真实装载线程复现旧版 Enter / Delete 问题：相同测试 APK，基线 2 项失败，修复后 4 项全过。
- E30 另通过旧候选线程延迟、真实外部输入框、个人词学习、重启和上下文选择，共 32 项专用模拟器场景。
- 本次发布重新构建与回归的数量、APK 摘要、签名和资产身份详见随包 `BUILD-INFO.json`。
- 故障注入只存在于测试工具，不进入 APK；受控等待时长不当作自然启动速度。

**跨音节换位纠错实验暂未纳入此版本。** 它提升了已知合成误触样本召回，但同机 ABBA
确认耗时 P95 从 265 ms 升到 291 ms，未通过预定门槛。实现和全部证据已提交仓库，未为了发布隐藏退步。
本包保持该实验之前的解码逻辑；E30 同轮固定工作负载为中位数 136.5 ms、P95 265 ms。
这些是专用 API 37 x86_64 模拟器观测，不是实体手机或全场景 100 ms 承诺。

自然同音句、部分人名和长句仍有改进空间，例如已知“今天有一点类 / 累”歧义。
没有操作用户手机；输入质量专项继续推进。

## 升级

同签名覆盖安装保留数据。沿用 rc.2 的 SQLite v4 个人词库；从更早版本升级时执行既有迁移。
如需回退，请先导出个人词条和配置，避免直接降级或卸载造成数据损失。
