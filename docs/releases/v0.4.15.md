# Sense v0.4.15 — Sense Mic 现代化 Windows 前端

- 发布日期：2026-08-24
- Tag：`v0.4.15`
- Android：`versionCode 40`，`versionName 0.4.15`
- Windows：`SenseMicSetup-v0.4.15-windows-x64.exe`
- Linux：`SenseMicClient-v0.4.15-linux-x64.tar.gz`

## Windows 前端

- Windows GUI 从固定坐标控件重写为 Slint 响应式界面，统一使用卡片、状态色、圆角和清晰的视觉层级。
- 首页集中呈现手机发现、手机到电脑的音频链路、IP、六位配对码、延迟档位和连接状态。
- 开始与停止合并为一个随会话状态变化的主操作；配对、传输和重连阶段均可立即停止。
- 运行记录默认折叠，仅保留数据包、丢包和抖动摘要；需要诊断时可展开完整输出。
- 设备版本号来自 Rust package metadata，避免后续发布出现界面版本漂移。

## VB-CABLE

- Windows 正式发行继续使用 Setup 内置并经过签名策略校验的 VB-CABLE。
- 主界面统一包装为“Sense Mic 虚拟麦克风”，同时显示并支持复制系统中的真实录音端点名称。
- 当旧版 SenseMicVAD 与 VB-CABLE 同时存在时，接收核心明确优先选择完整的 VB-CABLE 端点对。
- 驱动安装、扫描、连接和子进程输出均由异步任务回送 UI 事件循环，避免界面阻塞。

## 发布校验

- Rust GUI 测试、核心库测试、格式检查以及 Windows CLI/GUI 构建通过。
- Windows Release Policy 验证 VB-CABLE 获取、校验和 Setup 打包链路。
- 实际启动 Windows GUI，确认手机发现、VB-CABLE 端点、驱动状态及版本信息正确投影。
- GitHub Actions 构建固定证书签名 APK、Windows Setup、Linux 客户端及统一 `SHA256SUMS.txt`。
