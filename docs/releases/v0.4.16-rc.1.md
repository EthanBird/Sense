# Sense v0.4.16-rc.1 — 全拼输入质量预览版

- Android：`versionCode 41`，`versionName 0.4.16-rc.1`。
- APK：`Sense-v0.4.16-rc.1.apk`；沿用 Sense 正式证书，可覆盖升级同签名的旧正式版。
- 发布通道：GitHub Pre-release；保留 v0.4.15 为最新稳定版。
- 本版集中改进 26 键全拼输入，不重新发布 Sense Mic Windows/Linux 安装包。

## 输入体验改进

- 加入离线字级 N-gram 上下文模型，改进拼音词格中的整词与整句排序；无需网络或额外配置。
- 改进音节切分、漏键/多键纠错与未完成拼写的候选排序，保留正确拼写及主动选择的个人词。
- 修复字典已有常用词被有界前缀扫描漏掉的问题，例如 `beiji` 现在可直接选第二候选“北京”，“北极”仍为未学习时的默认首选。
- 加强个人词、分段造词和输入别名的学习与持久化；“程彻 / 智能体”及补全候选的复用、进程重启已有回归覆盖。
- 改进展开候选的连续滚动、候选身份绑定与分段候选可选性，减少等待解码时的视觉跳动与过时结果误提交。
- 联想与工具栏互斥，继续输入、切换输入框或主动关闭时撤销；触摸联想时暂停闲置收起。
- 完善大字号、横竖屏、候选无障碍节点与输入框切换等交互。

## 已完成的验证

基于同一生产解码源码的 E23 Debug 包：928 项主机测试、66 项专用模拟器输入场景通过；
Python 工具 409 项执行，其中 408 通过、1 项 Windows 符号链接权限相关测试跳过。
已知回归集的 752 个干净输入状态完整候选结果保持，2,833 条合成错拼指标与图证据保持。
这些是回归与诊断结果，不代表所有自然输入都准确，也不是用户手机上的性能认证。

正式签名构建、包身份、模型/词库资产、发布包校验结果单独记录在随包 `BUILD-INFO.json`。
研究 Debug 包通过的测试与正式签名包的静态核对分别报告，不混称为正式包的真机验收。

## 当前已知边界

- 长句首次解码、复杂纠错和快速确认仍可能出现明显等待。上一开发版本的模拟器提交到外部编辑框延迟观测中位数约 506 ms、P95 约 1.17 秒；本版尚无新的可比性能结论。
- 旧快打测试中的“32 ms”是设置值，实际事件间隔常超过 100 ms，不当作本版输入延迟或高速触摸认证。
- 无上下文的同音歧义、部分姓名与长句仍有改进空间，例如已记录的“类 / 累”误选。
- 本版因此先作为预览发布，性能推广门槛和整体输入质量目标继续保留，不把局部回归通过表述为全面达标。

## 升级与许可

同包名、同证书覆盖安装保留原应用数据。预览版 versionCode 已递增；直接安装旧版 APK 可能被 Android 拦下，
回退前请先导出需要保留的个人配置和词条，不建议通过卸载来尝试回退。
不迁移或清空现有个人词库。词库与离线模型的来源及署名在“关于 / 开源许可”中可查看。
