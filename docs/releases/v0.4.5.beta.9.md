# Sense v0.4.5.beta.9 — 中文九键与五笔 86

## 版本

- Tag：`v0.4.5.beta.9`
- Android：`versionCode 30`，`versionName 0.4.5.beta.9`
- 发布资产：`Sense-v0.4.5.beta.9.apk`
- 平台：Android 10+（`minSdk 29`，`targetSdk 36`）
- 发布性质：GitHub Pre-release
- 项目许可：GPL-3.0-only

## 中文九键

- 新增生产可用的 1–9 九宫格布局，数字、字母 legend、删除键和原有 Skills 长按语义完整接入。
- 数字串直接进入拼音音节 trie/DAG，不展开指数级字母组合；`1` 可显式固定音节边界。
- 候选栏展示数字原文与自动分词，例如 `486743697 · hun'shen'x's`，Top1 为“浑身解数”。
- 中文专用解码跳过英文词表，并复用现有拼音上下文与个性化学习。
- 完整解码采用 query 去重、路径多样性 Top1 探针、胜出路径有界扩展和 cooperative supersession。

## 五笔 86

- 新增五笔 86 全键输入、精确候选、前缀补全、`z` 拼音反查和字根键帽。
- 提供关闭、四码唯一、Rime 风格三种自动上屏策略；第五形码按事务提交并重放。
- 使用独立五笔个性化模型与 SQLite 数据库，选择、快速删除、立即替换均反馈到内存热路径。
- 精确候选始终位于补全候选之前，个性化只改变同组次序。

## 可复现词库资产

- 固定 `rime/rime-wubi` revision `152a0d3f3efe40cae216d1e3b338242446848d07`。
- SWBX/1 资产包含 99,054 个精确码、136,239 个精确候选、15,259 个补全前缀和 70,386 个反查字符。
- 构建器、源文件、manifest、统计、LGPL-3.0 全文和归属说明均进入源码与 APK 检查链。
- 本地门禁从固定源逐字节重建资产，并再次核验最终签名 APK 内的资产与许可副本。

## 架构与稳定性

- 新增独立 `ime-config` 模块，使用 `AtomicFile + sidecar file lock` 跨 app/IME 进程保存方案设置。
- 方案 epoch、composition revision 和 decoder generation 共同阻断陈旧异步候选。
- 语言模式、QWERTY/T9 几何与五笔 legend 通过一次原子安装切换，切换前取消在途 pointer，只重建一次最终 scene，修复闪烁与主题混色。
- 键帽视觉 legend 与上滑输出拆分，五笔字根不会改变既有手势输出。

- T9 完整混合解码：p50 2.002 ms、p95 5.395 ms、p99 7.093 ms。
- `486743697` 完整解码 p95 4.827 ms；显式边界 `64'426` p95 3.903 ms；32 位边界串
  p95 8.212 ms；96 位极限串 p95 5.508 ms。
- Wubi 热查询 p95 6.771 μs；SWBX/1 估算保留内存 7,089,539 bytes。
- T9 索引构建 91.39 ms；Wubi 冷加载、校验与原始索引构建 64.86 ms，均位于后台加载 lane。
- 签名 APK 为 26,893,701 bytes；相对 beta.8 增加 3,172,600 bytes（13.37%），主要来自压缩后的五笔资产与许可副本。

  既有性能门禁。
