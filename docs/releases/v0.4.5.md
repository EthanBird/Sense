# Sense v0.4.5 发布说明

## 版本

- Tag：`v0.4.5`
- 版本：`versionCode 20`，`versionName 0.4.5`
- 平台：Android 10+，`targetSdk 36`

## 键盘内 Skills

Skills 已从固定提示词升级为可长期维护、可配置键位并由 Agent 读取的完整系统：

- 长按可绑定按键后向四个方向滑动，在不改变键盘高度、不弹窗的情况下选择 Skill；
- 再次选择当前 Skill 会取消激活并恢复默认 Agent；
- 激活键显示动态极光，极光只重绘对应按键的独立子层，不带动整张键盘重绘；
- 键盘隐藏、按键不可见、系统关闭动画或 Skill 取消后，会撤销持续帧回调；
- Space 长按仍专用于唤醒 AI，Delete 连续删除和既有字符 flick 不会被 Skill 手势抢占。

## Skills 设置与完整历史

设置首页采用 Provider、记忆（Soul）、工具、Skills 的分层入口。Skills 页面支持创建、
编辑、绑定、解绑和历史恢复，并完整保留用户数据：

- Skill 正文按不可变 revision 保存，更新不覆盖旧版本；
- 绑定和激活状态按不可变 catalog generation 保存；
- `CURRENT`、`HIGH_WATER`、文件锁、原子替换和目录同步覆盖进程终止与写入故障恢复；
- 旧 revision、旧 catalog、崩溃窗口中的完整文件和未保存草稿不会被清理；
- IME 使用后台 projection 与 FileObserver 获取更新，按键热路径不扫描目录或等待落盘。

## Agent Skills 工具

默认 Agent 只看到每个 Skill 的简短 description，需要正文时可以智能调用
`skill_read`。用户在设置页启用管理能力后，Agent 还可以调用 `skill_manage`：

- 创建 Skill，可同时绑定或保持未绑定；
- 修改名称、description、完整正文和基础编辑意图；
- 绑定、解绑单个键位，或解绑某个 Skill 的全部键位；
- 使用 catalog generation 做冲突检测，避免覆盖用户或另一个进程刚完成的修改。

激活 Skill 的精确 revision 和 catalog generation 会在一次 Agent run 开始时冻结，正文
直接进入本轮上下文；后续设置变化不会让同一轮推理读到混合版本。合法的大型 Skill 通过
分页工具读取，Brain 请求在进入 Binder 前执行 448 KiB 上限检查。

## 兼容与质量

本版继承 v0.4.4 的联网搜索、网页读取、计算器、完整 Agent Journal 和本地记忆检索。
工具与 Skills 仍只能由用户在设置页决定是否启用；关闭能力不会删除已经保留的数据。

发布候选的确定性测试覆盖 795 项 JVM 用例。API 36 模拟器实际执行 18 项 AndroidTest：
17 项通过，固定物理机绝对性能测试按设计明确跳过。模拟器的三段 30 秒极光结构测试均
验证了 callback/draw/FrameMetrics 推进、父键盘零重绘、分配预算和停止后不再续帧。
完整发布流水线还会重新执行 Gradle、Lint、M0–M6、APK、签名、zipalign、权限 typed
value 与生产资产哈希验证。

## 已知证据边界

产品所有者于 2026-07-28 明确决定发布 v0.4.5，并接受以下证据在发布时尚未补齐：

- 4 项需要真实 Provider Key 的 opt-in 探针仍为 `SKIPPED`，真实 Key 通过数为 0；
- 固定物理设备的 Aurora `TOTAL_DURATION p95 <= 32 ms` 与目标帧率证明尚未执行；
- 完整系统 IME 宿主中的长期 StrictMode 与 `:brain` 跨进程交错仍需继续扩展实机证据。

这些项目不会被记为“已通过”，也不降低对应测试标准；它们作为公开的发布后验证任务
继续保留。v0.4.5 的模拟器结果只证明结构隔离和停止语义，不代表实体设备绝对性能。
