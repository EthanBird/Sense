# Sense v0.4.8 — Agent 交互、记忆与候选排序

## 版本

- Tag：`v0.4.8`
- Android：`versionCode 33`，`versionName 0.4.8`
- 发布资产：`Sense-v0.4.8.apk`
- 平台：Android 10+（`minSdk 29`，`targetSdk 36`）
- 发布性质：GitHub Stable Release
- 项目许可：GPL-3.0-only

## 输入法前端 Agent

- Agent 入口移动到键盘工具栏正中间，不再占用工具箱项目；入口始终位于输入法前端。
- Agent 页面压缩阅读区与底部留白，内置输入框扩展为最多四行，长提示词可以直接查看与编辑。
- 左上角使用明确的收起图标；收起只切换前端投影，后台运行中的 Agent 继续由 Brain service 持有。
- Assistant 消息新增“写入当前输入框”操作，通过当前 `InputConnection` 把结果显式提交到输入法面对的外部编辑器。
- 对话归档支持完整记录、历史会话切换与新会话创建，归档排序采用崩溃安全的稳定时间与标识组合。

## 记忆与 Skills

- `memory_search` 增加中日韩文本感知的 n-gram 查询、受限关键词采样和部分概念匹配，短中文偏好也能稳定召回。
- 工具结果返回实际 `result_count`，空结果与真实命中在 Agent 工具循环中可直接区分。
- 补充包含“海军蓝”和“简洁直接”等测试数据的集成覆盖，验证写入、索引、搜索与结果投影的完整链路。
- Skills 与记忆调用继续保留 session、revision 和工具结果边界，历史记录与当前会话投影互不覆盖。

## 中文输入与个性化

- 中文模式下按回车提交英文原文时，与点击候选词走同一学习语义；自定义英文词频持久化并在重启后恢复。
- 1–2 个字母的短输入最多展示一个英文候选，3 个字母最多展示两个，降低短拼音被整页英文补全挤占的概率。
- 完整拼写的英文单词保留强证据并最多排在候选第二位；即使中文候选页密集，也为准确的完整单词保留入口。
- 英文限制在统一候选排序完成后执行，中文 exact、整句和个性化候选的相对顺序保持稳定。

## 架构与生命周期

- Agent UI 继续运行在 `SenseInputMethodService.onCreateInputView()` 的统一根 View 中，与键盘同步出现并可独立收起输入框。
- Brain runtime 继续位于独立 `:brain` 进程；前端只订阅会话投影，窗口重建和输入目标切换不会接管运行所有权。
- 运行浮条、Agent 页面与系统通知继续提供停止入口，终端与浏览器工具维持 session-scoped 状态。
