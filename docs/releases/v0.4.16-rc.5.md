# Sense v0.4.16-rc.5 — 组词码表查找优化

- Android `versionCode 45`，沿用一直使用的正式证书，支持同签名覆盖升级。
- GitHub Pre-release；保留 rc.4 及所有旧附件，不替换 v0.4.15 最新稳定版。
- 本次仅发布 Android APK，Sense Mic 桌面客户端不变。

## 改进

组词搜索逐步延长拼音前缀时，复用上一前缀在码表中的区间，减少从全表重新查找。
不修改词频、语言模型、候选顺序、搜索预算、个人词库格式或 UI 布局；不新增常驻词典副本。
保留 rc.4 的跨音节换位纠错、个人词库恢复优化和既有输入生命周期修复。

## 验证范围

- 964 项核心/服务/UI 主机测试通过；40 项专用模拟器实际输入场景通过，覆盖学习与重启、隐私、上下文、纠错和显式分词。
- 3,083 个完整候选结果保持一致，基础/扩展视图 1,875,971 次前缀记录核对一致；词库及模型资产保持。
- 一次固定 API37 x86_64 模拟器 ABBA：确认中位数 **136→131.5 ms**，P95 **338→300 ms**，最大值 **343→309 ms**。
- 64 次快打确认和 8 次立即续打全部正确。“请检查一下邮件”等三组输入的中位数仍有增加，完整记录见 E42 报告。

上述功能及性能证据来自 E42 固定 Debug APK，不是此正式签名包的新一轮测量，也不代表所有手机。
发布阶段只提升版本并重新签名构建，另核对签名、包身份、资源、Release lint 和模块边界。
没有进行实体手机测试；没有将 E41 未通过性能门槛的字符缓存纳入发布。

这不是整体输入准确率提升的声明。自然同音句、部分姓名及长句仍有改进空间，“类/累”歧义仍在专项范围内。

## 升级

覆盖安装保留已有数据，沿用 SQLite v4 个人词库与既有迁移逻辑。回退前先导出个人词条和配置。
本包的 SHA-256、证书、源码与验证范围见随包 `BUILD-INFO.json` 和 `SHA256SUMS.txt`。
