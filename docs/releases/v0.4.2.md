# Sense v0.4.2 发布说明

## 版本

- Tag：`v0.4.2`
- 版本：`versionCode 17`，`versionName 0.4.2`
- 基线：`v0.4.1`
- 方向：`0.4.x` 继续完善 AI；本次不提前升级到 `0.5.0`

## Agent 状态机与锁定体验

- 新增显式 Agent 会话状态机，区分读取输入框、连接、理解、思考、生成、工具调用、校验、
  写入、恢复及终止；
- 上滑锁定只改变松手行为，不再把执行状态重置为“正常生成”，也不会清空已经出现的活动
  与预览；
- AI 主区域显示最近活动时间线，运行中、完成和失败均有独立标记；
- 模型还没有输出正文时显示明确等待提示；已有非空预览不会被非终止空帧覆盖；
- 锁定后继续提供右下停止键，停止会先撤销编辑权限，再中断 Binder 和 HTTP。

## DeepSeek 真实多轮反馈

- `sense.soul.v2` 将进度与最终提交分为两个原生工具；
- 模型先调用 `sense_report_progress`，Brain 校验并返回真实工具结果，模型再继续下一轮，
  最终只能调用一次 `sense_submit_patch`；
- 工具开始与结束按 call id 配对，公开反馈采用稳定 step 原位更新，不伪装模型思考过程；
- thinking mode 工具轮按 Provider 要求在 Brain 内回放 `reasoning_content`，但私有推理不会
  进入 IME、日志或 Binder；
- 最多两轮模型进度反馈，之后只开放终止工具，避免无限“正在处理”；
- 普通锁定会话采用 45 秒首事件、120 秒流空闲和 300 秒绝对上限。本地心跳只改善反馈，
  不会延长网络 watchdog 或最终上限。

开发期真实探针使用用户授权的 DeepSeek 临时凭据与 `deepseek-v4-pro` thinking mode 跑通
生产传输、流解析、多轮工具和终止协议：约 35.6 秒、60 个事件、28 个公开进度更新、4 个工具
状态更新、1 个终止 Patch。凭据没有写入仓库、日志或构建产物。普通 CI 不持有真实 Key，
因此该探针默认跳过，只有显式设置环境变量时运行。

## 新工具箱

- 工具箱由厚重 3 × 2 大卡片改为四列图标优先控制中心；
- 符号、文字编辑、语音、剪贴板位于首行，Emoji 与先思首页在第二行居中；
- 图标使用分类色和圆角底座，面板与键盘底色融为一体；
- 视觉间距保留，但每个完整 slot 都能命中；“先思首页”打开 Sense 设置首页。

## 发布门禁

GitHub Actions 创建 Release 前必须通过：

- protocol、brain-api、brain、runtime、service、UI 与 core 单元测试；
- Agent 状态转移、工具关联、心跳超时、真实多轮请求构造、reasoning 私有回放及终止 Patch
  回归；
- AI 锁定、取消、非空预览、恢复和编辑事务回归；
- 工具箱几何、入口路由和横竖屏回归；
- M0–M6 Host 正确性与性能基准；
- Android Lint、Debug/Benchmark/Macrobenchmark APK 编译；
- `versionCode 17`、`versionName 0.4.2`、SDK、签名、zipalign、权限白名单与生产资产验证。

## 已知边界

- 公开进度是模型提供的一行安全状态摘要，不是私有 chain-of-thought；
- Provider 或网络永久挂起仍会在绝对安全上限终止，停止键不等于取消所有失控保护；
- 输入框拒绝提供可定位全文且没有选区时，AI 仍会安全拒绝；
- GitHub 构建暂未使用固定发布签名，旧 APK 签名不同可能需要卸载后安装；
- 自动化与开发网络探针不能替代 HyperOS、Pixel、Samsung、OPPO/vivo 的宿主输入框和移动
  网络真机验收。
