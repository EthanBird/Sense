# Sense v0.4.16 — 中文输入质量与稳定性正式版

- Android `versionCode 48`，使用自 v0.4.7 延续的正式证书，支持同签名覆盖升级。
- 此版转为 GitHub 最新正式版；保留全部预览版及历史附件。
- 本次发布 Android APK，Sense Mic 桌面客户端保持原版。

## 本轮正式交付

汇总 v0.4.16 预览阶段已经落入 APK 的改进：

- 改善个人词学习与重启恢复、上下文候选和联想唤起/收起生命周期。
- 完善显式拼音分词、换位纠错及码表查找，保留个人学习与隐私边界。
- 修复词间搭配分未参与候选截断的问题，减少合理候选过早丢失。
- 减少拼音组词路径的重复字符串构造，降低临时对象分配。
- 增加从逐键输入到外部编辑框上屏的回归覆盖，以及最低支持 Android 版本、字号、横屏和受限应用堆验证。

相对 rc.7，正式版的输入算法、模型资产与 UI 不变；新增的运行堆诊断只读取运行状态。
E53–E56 的研究代码和评测证据保存在仓库，但新词级模型尚未接入 Android，**本 APK 不包含该模型**。
Agent / Skills 设置页改版属于后续更新，也未混入本次稳定版。

## 验证范围

沿用已经完成的 E48：973 项核心/服务/UI 单元测试、49 项专用模拟器功能检查；
3,083 个逐键状态的完整候选和 LM 调用等价验证。JVM 解码线程分配计数估计减少 6.38%。
同轮固定模拟器 A-B-B-A 的确认上屏延迟中位数 146→146 ms、P95 315→292 ms；
64 次确认和 8 次续打正确。它不是所有手机的体验承诺，也不是所有场景均低于 100 ms。

后续 E49 完成 API29/API37 配置矩阵 37 项，E51 在专用 API29 模拟器 112 MiB 应用堆下
完成加载预检及 49 项输入功能检查。相关结果来自固定 Debug APK，不当作新签名 APK 的设备实测。
发布阶段重新打包并检查原证书、版本、包身份与资产，执行 Release lint 和发布契约。
实际执行范围、缓存复核与产物身份分别记录在 `BUILD-INFO.json`。没有操作实体手机。

自然同音句和长句仍有误判；更成熟的词级模型已取得主机回放进展，移动端集成另行交付。
