# Sense v0.4.16-rc.6 — 组词候选保留修复

- Android `versionCode 46`，沿用原正式证书，支持同签名覆盖升级。
- GitHub Pre-release；保留 rc.5 及旧附件，不替换 v0.4.15 最新稳定版。
- 仅发布 Android APK，Sense Mic 桌面客户端不变。

## 这次修复了什么

组词搜索原来先按词频和部分语言模型分数筛选同音候选，随后才补上词间搭配分。
一个词即使与前文搭配合理，也可能在完整候选生成之前被提前丢弃。
本版把已有搭配分提前纳入筛选，并修复单字与整词边界共用选择缓存的问题。
词库、模型、评分常数、搜索预算、个人词库格式和 UI 布局保持不变。

保留此前的个人词学习与重启恢复、智能联想生命周期、显式拼音分词、换位纠错和码表查找优化。
未将尚未完成验证的 E47 缓存实验或 E43–E45 研究模型纳入本包。

## 已有验证及实际表现

- E46：969 项核心/服务/UI 单元测试、36 项评测工具检查通过。
- 49 项专用模拟器实际输入检查通过，覆盖“程彻”“智能体”的学习复用、进程重启、隐私、上下文、纠错、分词、联想及外部编辑框。
- 3,075 个已知整句/纠错状态的首选、前五、召回及字错汇总保持；控制反例得到修复。这不等于整体日常准确率已经提高。
- 同轮固定模拟器 A-B-B-A：确认延迟中位数 **140→149.5 ms**，P95 **311→295 ms**，最大值 **313→322 ms**；64 次确认及 8 次续打均正确。

这次是正确性修复，中位数有 6.8% 开销，符合事先设置的 10% 成本预算；更严格的零退步门槛未通过。
完整逐查询退步见 E46 报告。不宣称全面提速或普遍低于 100 ms。

上述 Android 功能与性能数字来自 E46 固定 Debug APK，非本正式签名 APK 的重新实测，亦不代表所有手机。
发布阶段重新构建、检查正式签名/包身份/资产、Release lint 和模块边界；具体记录见 `BUILD-INFO.json`。
没有操作实体手机。
