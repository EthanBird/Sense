# Sense v0.4.4 发布说明

## 版本

- Tag：`v0.4.4`
- 版本：`versionCode 19`，`versionName 0.4.4`
- 平台：Android 10+，`targetSdk 36`

## 开放 Agent 工具

设置首页新增 Agent 工具总开关与四项独立开关，默认开启，且只允许用户在设置页修改：

- `web_search`：免 Key 搜索公开网络；DuckDuckGo 遇到挑战或空结果时自动回退到
  Brave Search，两个后端都不可用时显式失败；
- `web_fetch`：读取指定网页的正文；
- `calculator`：本地确定性数学计算；
- `memory_search`：检索本机完整 Agent 历史。

Agent 会根据任务智能选择已开启工具。设置快照在 Run 开始时冻结，模型只看得到已开启
工具；执行路由会再次核对同一集合，猜测已关闭工具名不会执行。一次 Run 最多进行 6 次
工具轮次，每个结果进入同一 Provider 对话继续推理，最终仍必须提交唯一
`sense_submit_patch`。

## 完整 Agent 历史

`:brain` 现在始终追加保存：

- 完整编辑器请求与输入快照；
- Provider 请求正文和原始响应字节；
- 公开状态、流式预览与私有 Agent 内容；
- Tool call、参数、结果与错误；
- 最终 Patch、失败、停止和取消。

Journal 使用全局稳定 sequence、前帧链、CRC、文件锁、边界同步刷盘和进程重启恢复；
Provider 原始分片逐片写入文件而不在内存合并，只延后昂贵的 `force`。恢复只修复不完整的
物理尾帧，不静默截断有效记录。`memory_search` 使用有界词法检索，并排除当前 Run，避免
把自己的查询当成历史答案。关闭工具只停止后续调用，不会停止历史写入或删除已有数据。

## Android 授权模型

Sense 采用开放产品 profile：Android 系统已经授予的网络、应用私有存储及用户选择目录
能力可直接供对应 Tool 使用，不叠加重复授权。本版不新增系统权限，仍只声明：

- `android.permission.INTERNET`
- `android.permission.RECORD_AUDIO`

用户授权目录的文件读取、列表和写入 Tool 将沿同一 Tool ABI 在后续版本接入。

## 兼容与质量

本版保留 v0.4.2 的 Agent 状态机、上滑锁定、停止、公开活动时间线、流式恢复和
generation 隔离。网络内容和预览仍不能直接覆盖编辑器；最终文本继续通过结构化 Patch、
snapshot hash/CAS 与写后验证。

本地与 GitHub Actions 门禁覆盖 Tool schema/路由、多轮回放、设置 32 种组合、Journal
重启/断尾/损坏、当前 Run 排除、AI/IME/UI/Core 回归、M0–M6 性能、Lint、APK、签名、
zipalign、权限和生产资产哈希。免 Key 公网搜索另有显式启用的真实网络探针，普通 CI
使用确定性输入避免第三方搜索服务波动阻断构建。
