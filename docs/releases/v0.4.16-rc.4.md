# Sense v0.4.16-rc.4 — 换位纠错与个人词库性能优化

- Android `versionCode 44`，沿用原正式发布证书，支持同签名覆盖升级。
- GitHub Pre-release；rc.1 / rc.2 / rc.3 原附件保留，v0.4.15 仍是最新稳定版。
- 只更新 Android APK，不重新发布 Sense Mic 桌面客户端。

## 本次改进

**跨音节误触纠错**：相邻两个字母交换位置时，即使跨越两个拼音音节，仍按一次换位处理。
例如 `wobuxihuaznuoye` 可确认“我不喜欢作业”。明确输入的拼音分隔边界继续生效。
此前因性能退步暂缓的实现，经过有界音节边复用和排序优化，现已通过同一套耗时门槛。

**个人词库恢复优化**：减少容量淘汰扫描和空别名处理的临时对象，不修改词频、容量、数据库格式或历史记录。
一万词、共享别名的压力样本，Android 索引构造中位数约 1010→483 ms；
无共享别名对照约 98→82 ms。这是索引构造成本，不等同于每键输入或整个冷启动耗时。

保留 rc.3 的加载期间回车/退格响应修复，以及既有上下文学习、重启恢复和隐私隔离。
词库、离线语言模型及搜索预算不变。

## 已有验证与边界

- 最终输入实现已通过 955 项主机测试、34 项 Android 外部输入框/纠错/学习/上下文回归。
- 个人词库优化另有 56 次容量输入、4 次不同进程重启及记录持久化验证。
- 2,819 条既有误触回放、256 个跨域状态结果保持原纠错候选实现的结果；不是新盲测。
- 换位测试子集：首选命中 164→228/375，前十命中 235→328/375；
  两条已知漏键样本仍从第 3 名掉出前十，详情见 E34 报告，没有针对词句加特判。
- 同轮专用模拟器 ABBA：确认中位数 138→129.5 ms，P95 307→296 ms；
  最大值 312→346 ms，个别输入仍变慢，不代表全场景 100 ms。

以上功能和性能证据来自 E33/E34 的固定 Debug APK、专用 API 37 x86_64 模拟器，
不是本发布 APK 的新一轮实机测量。此次仅提高版本号并重新签名构建，复用已完成的输入回归，
另检查发布包签名、身份与资源。确切摘要、来源和检查范围见随包 `BUILD-INFO.json`。
没有操作用户手机。

自然同音句、部分人名和长句仍有改进空间，例如“今天有一点类 / 累”歧义；输入质量专项继续推进。

## 升级

同签名覆盖安装保留数据，沿用 SQLite v4 个人词库；更早版本执行既有迁移。
回退前先导出个人词条和配置，避免直接降级或卸载造成数据损失。
