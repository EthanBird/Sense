# Sense v0.4.7 — Agent 工作台、终端与浏览器

## 版本

- Tag：`v0.4.7`
- Android：`versionCode 32`，`versionName 0.4.7`
- 发布资产：`Sense-v0.4.7.apk`
- 平台：Android 10+（`minSdk 29`，`targetSdk 36`）
- 发布性质：GitHub Stable Release
- 项目许可：GPL-3.0-only

## Agent 工作台

- 键盘工具箱新增 Agent 入口，设置首页也可直接打开独立工作台。
- 工作台提供 Agent、终端、浏览器三个页签；Agent 对话支持连续消息、流式预览、停止任务、开始新会话和 Token 用量显示。
- 对话记录以有界、原子文件保存在同一 Agent session 中；Activity 重建或离开界面不再自动终止正在执行的任务。
- 新增 `ASSISTANT_MESSAGE` 结果模式，普通问答直接返回自然语言，不再要求模型把每次回答包装成编辑器 Patch。
- 输入法内的自然问答显示结果卡，可选择应用到编辑器、复制或关闭；编辑类 Skill 继续沿用 hash/CAS 与写后验证。

## 后台执行与生命周期

- Agent Hub 与 Brain service 同处独立 `:brain` 进程，前台界面只订阅投影，运行所有权由持久 runtime 保存。
- 用户发起长任务后升级为带通知的前台服务，并使用有界 partial wake lock 保持工具循环和流式输出。
- 通知可返回 Agent Hub 或停止当前任务；任务完成后释放前台状态和 wake lock，并发布完成通知。
- 会话、工具调用和 UI 使用同一个稳定 session identity，保证终端工作区、浏览器标签和对话连续一致。

## 终端

- 新增模型工具 `terminal_exec`，同时在 Agent Hub 中提供可直接操作的终端页。
- 每个 Agent session 使用独立的应用私有工作区与 `HOME`；`cwd` 只接受工作区相对路径并执行 canonical containment 检查。
- 命令通过 Android `/system/bin/sh` 以应用 UID 执行，支持独立 stdout/stderr、退出码、1–60 秒超时和超时终止。
- stdout/stderr 分别有 24 KiB 上限与截断标记，工具结果使用紧凑 JSON，避免长输出持续占用模型上下文。

## 浏览器

- 新增模型工具 `browser_use`，支持 `navigate`、`snapshot`、`click`、`type`、`back`、`forward` 与 `reload`。
- Agent 使用 session-owned WebView：Cookie、历史和 DOM 状态持续保留；用户打开浏览器页签时接管的正是同一个 WebView。
- DOM snapshot 提供当前 URL、标题、正文摘要和可交互元素编号；模型可按编号点击、输入并提交表单。
- WebView 使用独立进程数据目录，开启 JavaScript 与 DOM Storage，关闭文件/内容访问并阻止 mixed content。
- 浏览器标签池、正文、元素数量、脚本等待和导航等待均采用明确上限。

## Agent 协议与工具控制

- `terminal_exec` 与 `browser_use` 进入稳定工具 ID、模型 schema、严格参数解码、设置开关和 exact admission mask。
- 工具调用携带稳定 `sessionId`，而 `requestId` 继续标识单次 run，两者职责分离。
- 模型猜测隐藏工具、提交格式错误参数或调用未启用工具时，Brain 将紧凑 typed error 作为 tool result 回送并继续当前对话，减少整轮修复重试带来的 Token 消耗。
- Agent 终局事件新增普通回答通道并完整穿过状态机、IPC codec、recorder、客户端和 UI；旧的编辑器 Patch 通道保持兼容。
