# Sense v0.4.13 — Sense Mic 桌面端与稳定传输

- 发布日期：2026-08-22
- Tag：`v0.4.13`
- Android：`versionCode 38`，`versionName 0.4.13`
- Windows：`SenseMicSetup-v0.4.13-windows-x64.exe`
- Linux：`SenseMicClient-v0.4.13-linux-x64.tar.gz`

## Sense Mic Windows GUI

- 新增原生 `sense-mic-gui.exe`，提供手机发现、IP 直连、六位配对码、延迟选择、连接/停止和实时运行记录。
- GUI 通过受控子进程运行既有 Rust 接收核心；关闭窗口会终止音频进程，配对码只进入子进程环境且不写入日志或磁盘。
- 新增 Inno Setup 安装器、开始菜单/桌面/开机启动选项和完整卸载入口。
- 安装器内含 GUI 与命令行接收端。驱动页支持选择并以管理员权限安装经过微软签名的 `SenseMicVAD.inf`。
- 公共 Setup 保持客户端交付边界；测试签名的 WaveRT 驱动不会进入 Release。未来提供 Partner Center 返回的 WHQL 目录时，同一打包脚本会验证后将驱动纳入 Setup 并在安装阶段部署。

## Android 手机端修复

- 修复前台服务启动状态、网络变更后的发现广播和控制连接生命周期。
- 连接建立前保持 UDP 发现可用；修复配对、断线与重连之间的状态竞争。
- 增强局域网地址选择、广播目标枚举和启动错误回滚，避免 UI 显示运行但端口未监听。

## Windows 接收核心修复

- 发现包按活动 IPv4 网卡逐一广播，并提供指定 IP 的稳定直连路径。
- 统一 CLI 退出码、错误输出、Ctrl+C 停止和子进程清理语义。
- 修复 `pnputil` 在 CP936/OEM/UTF-16 输出下的解码，并加强驱动包签名和公开发布门禁。

## 发布校验

- Rust：`cargo fmt --check`、单元/集成测试、`cargo clippy --all-targets -- -D warnings`、release 构建。
- Windows：GUI 实际启动、窗口渲染与关闭检查；Setup 静默安装、文件/快捷方式/卸载注册项和静默卸载检查。
- Android：核心模块 JVM 测试、Mic runtime 测试、Lint、签名 APK 构建与固定证书 SHA-256 校验。
- 所有资产写入 `SHA256SUMS.txt`。
