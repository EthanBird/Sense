# Sense v0.4.10 — Provider 与 Action Skills 长期管理

- 发布日期：2026-08-09
- Tag：`v0.4.10`
- Android：`versionCode 35`，`versionName 0.4.10`
- 发布资产：`Sense-v0.4.10.apk`、`SHA256SUMS.txt`
- 最低系统：Android 10 / API 29

## 设置层级

- Provider 目录、Provider 详情和 0 Token Action Skills 各自成为独立页面。
- Provider、API 协议、结构化输出与推理强度不再使用下拉选择。
- 子页面保留明确的父级返回关系，便于后续持续增加 Provider 和 Action。

## Provider 目录与 Codex 订阅

- Provider 目录覆盖 jcode 的 models.dev Provider 集合，以及 `kimi-for-coding`、
  `tencent-tokenhub-ep` 两个静态 Provider。
- 模型、Base URL、协议、结构化输出和流式选项仍可逐项覆盖。
- Codex 订阅使用 OpenAI 官方设备代码授权端点；Sense 从 Android 打开系统浏览器，
  用户在 OpenAI 页面完成登录，一次性代码最长等待 15 分钟。
- access / refresh token 作为一个加密会话包保存在 Android Keystore 后方；请求时仅短暂
  解密，使用 `ChatGPT-Account-ID` 与 Codex Responses 端点，并在到期前自动刷新。
- API Key 与订阅令牌使用不同认证类型，不会互相沿用或误当作同一凭据。

## Action Skills

- 设置首页新增“Action Skills · 0 Token”入口。
- 首个 `market.xauusd` Action 可独立启用或暂停；禁用后 Agent 入口与执行许可同时关闭。
- 设置使用跨进程原子文件保存；已有 Action History 和 Keystore 凭据不会因开关而删除。
- UI 明确显示稳定 ID、直连 API 与 0 Token 执行边界，为后续认证型 Action 保留管理结构。

## 验证与发布

- Provider 目录测试固定检查完整条目数、jcode 静态 Provider 与 Codex 端点。
- 导航测试覆盖 Provider 目录与详情之间的父级返回。
- Provider 请求对象继续对 Authorization 与 ChatGPT Account 头执行日志脱敏。
- 正式 APK 必须沿用仓库既有发布证书；未配置持久签名信息时 release 构建仍会拒绝执行。
