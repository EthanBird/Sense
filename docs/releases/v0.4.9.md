# Sense v0.4.9 — 可进化记忆与 0 Token Action Skills

- 发布日期：2026-08-09
- Tag：`v0.4.9`
- Android：`versionCode 34`，`versionName 0.4.9`
- 发布资产：`Sense-v0.4.9.apk`、`SHA256SUMS.txt`
- 最低系统：Android 10 / API 29

## 1. 双轨完整记录

本版本明确区分两类事实，并同时保留：

1. **Session Evidence Archive**：完整请求快照、Provider 原始输入输出、公开与私有事件、
   工具调用和结果、预览片段、最终回答、失败及取消终态继续写入单写追加式 Journal。
2. **Experience Event Ledger**：只在稳定边界追加 `sense.agent.experience.v1` 语义事件；
   每条事件都携带 `source_record_ids`，回指不可变原始证据。

经历事件是检索旁路，不承担替换原始 Session 的职责。召回配额会显式为
`session_evidence` 保留位置，再合并 `experience_event` 与 `action_skill_history`。

## 2. 事件驱动的跨会话召回

- Brain 在 Provider I/O 之前，从最新用户任务提取有界查询。
- 统一召回返回记录 ID、通道、证据链接、扫描记录数、扫描字节数及截断标记。
- 首轮提示词获得冻结的 `sense_recall` 证据框；当前请求优先于历史证据。
- `memory_search` 工具使用同一数据面，并在结果中公开 coverage 信息。
- 当前 Run 按 `requestId + runGeneration` 排除，避免召回自身尚在写入的轨迹。
- 连接探针不注入历史证据。

## 3. 0 模型 Token Action Skill

输入法 Agent 前端新增紧凑的直接 Action 区，首个内置能力为 **黄金现价**：

- 直接请求 `https://api.gold-api.com/price/XAU`；
- 不创建 Provider 或模型请求；
- 结果卡显示 XAUUSD 美元/盎司报价、来源时间与 `0 Token`；
- 支持刷新、将报价交给 Agent 继续分析、写入当前外部编辑框；
- 完整 Connector 响应写入独立追加式 Action History，并参与后续跨会话召回；
- 请求有 HTTPS、状态码、超时和 128 KiB 响应上限。

`brain-api` 新增稳定的 Action Skill 描述、调用、结果和认证引用类型。认证型 API 使用
opaque credential handle；`AndroidActionCredentialVault` 以 Android Keystore 中的
不可导出 AES 密钥执行 AES-GCM 加解密，业务 Skill 只在一次调用租约中接触凭据。

## 4. 输入法前端交互

- 空闲态显示“黄金现价 · 直连 API · 0 Token”入口。
- 运行态提供独立停止入口，不影响正在后台运行的模型 Agent。
- 成功态提供刷新、分析、写入三项动作。
- “写入”继续复用当前 `InputConnection` 的外部编辑器写入路径。
- “分析”把已取得的结构化行情作为新用户消息交给 Agent，不重复抓取行情。

## 5. 验证覆盖

- `AgentRunRecorderTest`：语义旁路引用原始 Journal sequence，原始记录仍在原位置。
- `JournalAgentMemorySearchSourceTest`：以“海军蓝 / 简洁直接”种子数据覆盖原始 Session、
  经历事件、证据链接与 coverage 的生产适配器链路。
- `OpenAiRequestFactoryTest`：原始 Session 与语义事件同时进入首轮跨会话提示词。
- `DirectActionSkillRuntimeTest`：固定 XAUUSD 响应的解析、金额格式、0 Token 标记与
  错误标的拒绝。
- `ActionMemoryInstrumentedTest`：Action 原始结果跨 Store 实例召回；Keystore 凭据
  save/lease/revoke 生命周期。
- 正式发布脚本运行全模块 JVM/Android 单元测试、Lint、AndroidTest 装配、M0–M7、
  release 构建、APK 元数据与签名证书校验。

## 6. 签名与连续升级

正式 APK 沿用 Sense v0.4.7 起的持久 PKCS12 发布证书。发布脚本固定校验证书 SHA-256：

```text
76db888ff42b04d52d4d19a573fe8f8df2fa3af0ab36bd6a08c6f70a8aace984
```

GitHub Release 同时提供 APK 与 `SHA256SUMS.txt`；脚本会重新下载远端资产并再次核对
Git commit、APK SHA-256、版本元数据和签名证书。
