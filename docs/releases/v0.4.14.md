# Sense v0.4.14 — Sense Mic Windows 驱动修复

- 发布日期：2026-08-23
- Tag：`v0.4.14`
- Android：`versionCode 39`，`versionName 0.4.14`
- Windows：`SenseMicSetup-v0.4.14-windows-x64.exe`
- Linux：`SenseMicClient-v0.4.14-linux-x64.tar.gz`

## Windows 驱动与 Setup

- Windows Setup 现已内置基础版 VB-CABLE，并在安装过程中自动部署，不再要求用户查找或选择 INF。
- 内置包固定从 VB-Audio 官方地址取得并校验 SHA-256；Setup、catalog、INF 与 SYS 还会经过签名、kernel-policy 和 catalog 成员关系检查。
- VB-CABLE 的 catalog 由 Microsoft Windows Hardware Compatibility Publisher 签署，可在开启 Secure Boot 的普通 Windows 10/11 上加载。
- GUI 统一显示“Sense Mic 已就绪”，并明确标注“电脑应用麦克风”和“音频写入端”；诊断记录仍保留实际 VB-CABLE 后端归属。
- VB-CABLE 是可被其他程序共享的独立音频组件，卸载 Sense Mic 时予以保留；安装目录含来源、donationware 和许可说明。
- Setup 自动创建仅限 Private 网络、且绑定 `sense-mic.exe` 的入站 UDP 音频规则；卸载时同步移除，修复控制连接成功但 `received=0` 的超时循环。

## Windows 接收核心

- 驱动状态只接受同一后端的完整播放/录音端点对，避免把两个不相关的半套设备误报为就绪。
- `sense-mic driver install` 优先安装随 Setup 提供的 VB-CABLE，同时保留未来正式签名 SenseMicVAD 包的兼容入口。
- 新增 `sense-mic driver verify-audio`：向虚拟播放端点注入 997 Hz 测试音，再从虚拟麦克风捕获并校验样本数、峰值与 RMS。
- 驱动已就绪时安装操作保持幂等，不会重复创建设备。
- 心跳 PONG 新增手机已发送包数。桌面端超时时可区分“手机采集未产包”和“手机已发送但 Windows 入站 UDP 未到达”，并输出对应诊断。

## Android

- 版本号升级到 0.4.14；PONG 诊断载荷向前、向后兼容：旧桌面端会忽略载荷，新桌面端也接受旧手机的空 PONG。
