# Sense v0.4.5.beta.8 — Streaming ASR, undo/redo, and Skills UX

## 版本

- Tag：`v0.4.5.beta.8`
- Android：`versionCode 29`，`versionName 0.4.5.beta.8`
- 发布资产：`Sense-v0.4.5.beta.8.apk`
- 平台：Android 10+（`minSdk 29`，`targetSdk 36`）
- 发布性质：GitHub Pre-release
- 项目许可：GPL-3.0-only

## 英文符号映射修复

- 英文模式下字符键的滑动符号统一使用 ASCII 符号，不再混入中文全角标点。
- `M` 键恢复为 `/`，并补齐英文字符滑动映射的回归覆盖。

## 可选流式语音

- 搜狗在线语音继续作为免配置 Provider，选中后可直接使用。
- 新增“流式优化（边说边转）”开关，说话过程中持续提交中间文本。
- 设置页明确标注：启用后反馈更快，但准确率可能降低；关闭时继续使用完整录音识别路径。
- 流式链路支持增量 PCM16 采集、20 ms Opus 分帧、中间结果覆盖、最终结果提交、取消与超时。

## 撤销与重做手势

- 长按 `Z` 后下滑执行撤销。
- 长按 `Y` 后下滑执行重做。
- 优先调用编辑器上下文动作，并保留按键事件回退；这两个方向槽位作为键盘内置手势保留。

## Skills 绑定器

- Skills 配置页绘制完整可点击键盘，点击目标键位即可选择绑定方向。
- 当前绑定、选中键位与保留手势在键盘上直接呈现，减少列表与键位之间的来回查找。
- 原有绑定仍可查看和解除，升级不会覆盖用户数据。

## Skills 创建体验

- 新建入口改为模板优先：可从润色、翻译、总结、回复等常见意图快速开始。
- 创建表单按“用途 → 指令 → 绑定”组织，并提供实时摘要、完成进度与更明确的下一步动作。
- 历史版本默认折叠，让首屏聚焦创建和绑定；高级编辑能力继续保留。
