## 搜狗在线语音：选择后直接使用

语音 Provider 新增“搜狗在线语音（免配置）”。用户只需在设置页选择并保存该选项，
无需填写 API Key、endpoint 或模型，即可从键盘语音入口执行在线识别。

适配器完整内置 SRSS 协议：

- AES-256-CBC/PKCS5Padding 加密配置；
- RSA-OAEP-SHA256 封装每次请求的随机 AES Key；
- 16 kHz mono PCM16 通过 Concentus 编码为 Opus VOIP；
- 每帧固定 20 ms，即 320 samples / 640 PCM bytes；
- 每条 WebSocket binary message 使用 2-byte big-endian 长度头；
- 支持中间结果覆盖、最终结果单次提交、取消、总超时和响应大小上限；
- PCM、WAV 与 Opus 临时缓冲在终态清零，不写入文件。

本轮还修正了输入归档示例把 640-byte PCM 块误传为 `frame_size=640` 的单位问题。
Opus 的 frame size 是每声道采样数，正确值为 320。修正后服务端报告音频时长
`7.600s`、置信度 `0.86`；Python 复现与 Sense Kotlin live probe 均精确识别：

> 你好，我是银狼，来自星穹铁道，这是搜狗输入法语音识别接口的测试。

完整协议、归档摘要与探针命令见
[`docs/research/sogou-asr-provider-integration-2026-08-01.md`](../research/sogou-asr-provider-integration-2026-08-01.md)。

## Provider 与设置边界

- 搜狗预设标记为免凭据且运行时可执行；
- endpoint/model 固定为内置协议数据，不出现在可编辑高级连接设置中；
- 原有系统识别、OpenAI-compatible、Deepgram 与 DashScope 配置继续保留；
- IME 的凭据启动检查改为读取每个 preset 的真实 credential requirement，免 Key
  Provider 不再被云端模式的通用 Key 检查拦截。

## Windows 原生工程预览

仓库新增 `windows/` 原生端工程预览：C++20 TSF 输入法 DLL、SPLX v3 本地拼音
解码器、UILess 候选接口、Arctic 候选条、x64/x86 安装脚本、Windows 设置中心和
