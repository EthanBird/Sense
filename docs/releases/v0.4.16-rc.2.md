# Sense v0.4.16-rc.2 — 上下文记忆预览版

- Android：`versionCode 42`，`versionName 0.4.16-rc.2`。
- 沿用 Sense 正式发布证书，可覆盖升级同签名旧版本并保留应用数据。
- GitHub Pre-release；不覆盖 rc.1，不调整 v0.4.15 稳定版，不重新发布 Sense Mic 桌面安装包。

## 相比 rc.1

- **同音词按上下文记忆**：明确选择“人民→权力”“获得→权利”后，分别复用对应选择，不再只由全局词频互相挤掉。
- **记忆重启后保留**：原个人词库就地增加上下文字段，兼容 v1/v2/v3 数据；保留原词条、频次和输入别名。
- **避免错误学习**：默认 Space 接受保持原频次学习，但不覆盖明确的上下文选择；快速删除/立即替换撤销对应偏好。隐私字段和密码框维持隔离。
- **纠错查询内复用**：复用同次纠错中的词边筛选结果，保持搜索评分与预算；没有将未经回归门槛的新训练模型放进本包。
- 同步 APK 内总署名说明与仓库 NOTICE，补齐语料来源及模型变换说明；模型和逐句作者数据保持原样。

上下文记忆仅在本地保留相邻两个汉字，每词最多 8 个上下文。最近 30 天的明确改选参与上下文优先；
过期只停止此优先规则，词条仍保留。它改善个人适应，不等同于理解整段语义。

## 验证范围

E29 相同输入源码的 Debug 包通过 939 项核心/服务/UI 主机测试及 24 项专用 Android 模拟器测试，
包括“程彻 / 智能体”、同音词分别学习、真实进程重启、隐私字段和外部编辑框。
旧包用同一测试 APK 复现上下文选择失败，修复包通过。
生产参数下的 256 个无个人学习完整候选结果指纹与基线一致；这是已知回归，不是新盲测。

本次发布另做个人词库容量回归、正式签名构建和包身份/资产核对，结果见随包 `BUILD-INFO.json`。
正式包静态核验、Debug 模拟器功能证据、Windows JVM 查询成本分别报告，不混称手机实测。

## 仍在改进

- E27 固定模拟器工作负载的确认延迟中位数 137.5 ms、P95 298 ms；仅是该工作负载观测，
  不是本包全场景性能认证，也不是稳定 100 ms。复杂纠错、长句和首次装载仍可能等待。
- 冷装载未完成时按 Space 的确定性系统覆盖仍有缺口；保留待确认状态的功能已有其他测试，但该边界不算验收通过。
- 无上下文的同音句、部分人名和自然长句仍有误选，例如已知“今天有一点类 / 累”歧义。
- 仅使用专用模拟器，没有操作用户手机。总体输入质量专项继续推进。

## 升级与回退

覆盖安装保留数据；个人词库升级到 SQLite v4，旧版没有向下迁移能力。
请勿直接降级安装或卸载试错；如需回退，先导出个人词条和配置。
词库及离线模型资产保持原版本，来源和许可证仍可在“关于 / 开源许可”查看。
