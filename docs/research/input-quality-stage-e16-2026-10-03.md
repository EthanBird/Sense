# E16：概率空间多域融合与词格退步定位

## 产品结论

固定三档融合权重全部未过双域开发门槛，**保持默认模型和 APK，不打开测试候选**。
这次实现真实的条件概率融合而非混合语料计数；新领域改善，但日常退步仍在。
下一步针对词格边界证据与字符模型的重复计分做消融，不继续扫描更小的融合权重。

## 实现与依据

新增 opt-in `LinearMixtureCharacterModel`，由 M21 主机入口调用，应用工厂未接线。
保留 E15 的两份模型：当前日常 SCNG 与旧新语料平衡 SCNG。
`P = (1-alpha) P_daily + alpha P_balanced`，先 log-sum-exp，再进入既有 +6、截断、OOV −4、权重 .5 和查询归一化。
已有字符状态、分段路径、个人词保护和原得分诊断不改。

两份词表取并集时，每份模型的 UNK 按另一份 unigram 概率分配给其缺失的并集字符和残余 UNK，
避免把整块 UNK 概率分别赋给每个新增汉字。端点 0/1 直接返回原模型，不解析未使用的一侧。
数组只读，无逐查询文本和可变适应状态；额外推理和装载成本仍待 Android 验收。

[Shao 等，2020](https://aclanthology.org/2020.nli-1.3/)讨论模型插值与 OOV 处理；
[Koehn 与 Schroeder，2007](https://aclanthology.org/W07-0733.pdf)比较领域模型适应；
[Huang 等，2020](https://arxiv.org/abs/2008.02385)也提示困惑度和最终词错指标未必同步。
本实现是两个小型字符 n-gram 的条件概率融合，不是上述神经模型或 MDI 算法的复现。

## 固定开发试验

在输出前锁定 `e16-mixture-policy.json` 和 93 项文件。alpha 只取 .1、.25、.5。
两域都要求首选/前五/召回非降、字错非增，新域首选严格提升；过关者按总首选、总字错、总前五、小 alpha 顺序选一档。
开发数据是已知 E15 AISHELL dev 和已知 E13 日常 dev，各 64 句、128 状态，不冒称新开发盲测。

| alpha | AISHELL 首选 / 前五 / 字错 | 日常首选 / 前五 / 字错 | 结论 |
| --- | --- | --- | --- |
| 当前基线 | 65 / 97 / 142 | 83 / 113 / 70 | 保留 |
| .1 | 79 / 105 / 94 | 81 / 113 / 74 | 日常退步 |
| .25 | 82 / 105 / 88 | 81 / 113 / 74 | 日常退步 |
| .5 | 83 / 104 / 87 | 81 / 112 / 74 | 日常退步 |

每域状态数都是 128，字错分母 AISHELL 1,087、日常 941。状态包括整句及提供前两字正确上下文的中点后缀。
三档在日常集均 1 次首选改善、3 次退步，后两次源于同一句的整句和后缀状态，不能当作独立用户样本。
新域各有 15/18/19 次改善、1 次退步；所有 rank loss 和前五列表均保留。
开发冻结 `selectedAlpha=null`，没有用测试集再挑一次。

## 真实路径为何退步

回查与当前基线完全等价的 E13 M19 原始路径，查询 `sanbuzenmeyang`、上文“一起”：

| 路径 | 字典边权重 | 字符 LM 特征 | 完整含先验得分 |
| --- | --- | ---: | ---: |
| 散步 + 怎么样 | 2,247 / 15,569 | 1.7413999 | 17.66415 |
| 三 + 不怎么样 | 43,160 / 1,395 | 1.1461582 | 17.55347 |

错误路径具有约 **.23278 的词频优势**与 **.25178 的旧边界 bigram 优势**。
当前模型的 LM 优势 .59524 才让目标以约 .11068 领先，融合后失去这点领先。
同样的三项退步为“跟我们一起散步怎么样”“散步怎么样”“近露天过夜吗”。
这是实际得分分解，不是词条删除；边界 bigram 只在词边界给分，而字符 LM 已经覆盖相同字符转移。
下一试验检验保留字符 LM 时移除这项旧边界证据的效果，仍保留无 LM / 个人新词 backoff 的原行为。
该解释是由观测提出的假设，尚未把“去掉边界分就会提升质量”当作结论。

## 完成的验证

- 340 项 core 单元通过（新增 9 项：概率质量守恒、不同词表 UNK、二进制回退、并发和端点行为等）。
- 388 项 Python，387 通过、1 项 Windows 符号链接权限检查跳过。
- 主回放 1,024 状态；固定 .25 档两域重复 256 状态，完整结果一致。
- 两域 0 档与 E15 原 progressive SHA 完全一致，共 256 状态。
- 实际两份 SCNG、3,955 项并集词表、24 个条件分布的概率质量误差最大 `3.782487167924842e-8`。
  对照直接重复 UNK 的错误做法，质量和落在 1.0035–23.1373；这只是分布正确性对照，不是质量提升指标。
- 本轮没有新 Android 测量、UI/service 单元重跑、APK 构建、commit 或 release。原生产资产与 APK 字节保持。

门槛结果：`benchmarks/results/e16-acceptance-gate.json`；文件快照：`e16-evidence-manifest.json`。
未部署的实现保留为实验入口，不扩大对外能力承诺。总输入质量/UI/延迟目标继续。
