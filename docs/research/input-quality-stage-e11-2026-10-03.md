# E11：上下文规则的独立评测与撤回

日期：2026-10-03。**结论：本阶段的排序改动未通过质量门槛，未进入默认 APK。**

保留 E10 的生产算法与 Unicode 上下文修复。本阶段交付的是新增的家族隔离评测、
版本对照工具、三项试验及反例，以及已验证的源码/构建恢复。
不是一次输入准确率升级，也不是 release。

## 1. 为什么做这轮试验

E10 得分诊断发现，“价格 + shiliangnianqiandeliangbei”被旧词库的“格式”搭配加分推成了
“式两年前的两倍”。仅看这个例子，统一分数尺度似乎合理。
本轮先建立中性 LM、固定词库、固定外部搭配分的测试，再检查这种修改是否普遍改善自然句子。

三个开发阶段，均保持 LM 模型、词库字节、个人词规则、搜索上限和服务/UI 不变：

1. **统一长度缩放**：外部 bigram 与词频/LM 使用相同 query normalizer；相应调整词格内的搜索尺度。
2. **相邻搭配竞争**：已有前文二字的搭配分，抵扣与候选首字形成的重叠搭配分。
3. **完整词约束的竞争**：只有前文二字本身是主词库中 source tier 0 的完整词，才参与抵扣。
   单字前文、六字母以内输入、负分、空/禁用 LM、个人新词回退保持原行为。

第三项试验从现有 SPLX 解析出共享、只读、排序后的双字 key 数组，不新增资产。
构建器有 262,144 条输入上限；超出时整项提示关闭而非保留词表前半段。
这些实现和 8 个测试已经封存为研究源文件，**随后均从生产源集移除**。

## 2. 新数据与隔离

- `benchmarks/corpus/p2c-context-v5/`：固定哈希选样，32 个 dev 家族、64 个 test 家族。
- 排除此前所有 P2C proposal 的家族与文本，再执行既有 train/dev/test 近重复和子串审计。
- 一条开发句因近邻重叠排除，不补抽；最终 **31 条开发句、64 条测试句**。
- 逐句查看汉字和拼音后，修正了“等著”的 `zhe`、“他的”的 `de`、“长外套”的 `chang`。
  保留原文字形，不按候选结果更改文字或标签。审核者是 Codex，不宣称独立人工金标准。
- 署名、Tatoeba 来源许可、选样政策、原始 proposal、审核记录、冻结哈希全部保留。
- 每个汉字切点形成一个已知正确前缀与剩余全拼后缀：开发 **270** 个、测试 **550** 个。
- 运行 empty / editor / boundary / accepted 四模式，仍是合成的正确前缀重建，不是用户自然输入统计。

门槛在读取各开发输出前保存；第三项的源代码、资产、政策与开发报告在测试解码之前冻结。
要求首选、前五、255 内召回均不下降；报告所有首选/名次损失。
无前文、句号边界、六字母以内输入的完整结果须保持；外部前文与已选组合段须等价。

## 3. 开发结果与选择

同一组 270 个有前文后缀：

| 版本 | 目标首选 | 前五 | 255 内召回 | 首选增加 / 损失 |
|---|---:|---:|---:|---:|
| E10 基线 | 203 | 255 | 268 | — |
| 统一长度缩放 | 201 | 251 | 267 | 1 / 3 |
| 未约束的搭配竞争 | 204 | 253 | 268 | 1 / 0 |
| 完整词约束的竞争 | 204 | 255 | 268 | 1 / 0 |

第一项损伤“枪→击”“左→右”“警→卫”的正确续接，所以没有采用。
第二项把“在中”“的时”这类长词内部的二字片段也当成完整词，导致两个前五损失。
第三项在开发集无目标名次损失，才进入冻结测试；不是因为它修好了一个已知句子就直接打包。

试验测试本身也经过排错：初版长度测试把 13 个字母误算为 12，随后修正；显式分词测试补齐了
fixture 的单音节库存。最终选中试验的相同 5 个行为测试在封存的旧 bytecode 上失败 2 个，
在试验代码上全部通过，另有 3 个索引边界测试。早期错误与修正日志均保留，不把它们当成产品回归。

## 4. 冻结测试失败，停止推广

首次用于本次候选选择的 550 个测试后缀：

| 版本 | 目标首选 | 前五 | 255 内召回 |
|---|---:|---:|---:|
| E10 基线 | 432 | 513 | 542 |
| 完整词约束的竞争 | 430 | 513 | 542 |

首选增加 1 条、损失 3 条；另记录全部 5 条目标名次下降：

| 前文 | 原正确后缀 | 试验首选 |
|---|---|---|
| 你就 | 有了原动力 | 游乐园动力 |
| 你有 | 权使用旅馆的游泳池 | 全是用旅馆的游泳池 |
| 人有 | 权损害另一个人的生命 | 全损害另一个人的生命 |

唯一首选增加为“不 会”两字前文（实际连续文本 `不会`）后的“像井底之蛙”，原先是“想井底之蛙”。
字典收录了许多功能性短语，因此“词库里的二字词”也不是稳定的语法词边界。

在已知的 E10 540 后缀上，试验首选 397→398，修好了“价格→是两年前的两倍”和
“个月→以来一直在读古兰经”；但“做的→话什么都不会改变的”退为“画什么都不会改变的”。
这些旧例改善不足以推翻独立测试的失败。

**未在测试结果出来后改权重、加词条特判、删除坏样本或继续调该测试集。**
下一轮应把这些样本标记为已知回归，而非新的选参盲测。

## 6. 对下一阶段的影响

本阶段证明：单个词库搭配确实会造成错误，但手工削弱它也会移除有用信息；
语义词边界、功能词和重叠词不应由一个双字成员标志替代。
下一步先完成**得分特征分解与可复现的句子监督排序实验**，详见
`docs/development/input-quality-learned-ranker-v1.md`。
在新的独立质量与系统门槛通过前继续保留当前默认模型，整体目标继续。
