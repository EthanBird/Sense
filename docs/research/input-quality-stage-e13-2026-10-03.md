# E13：第一轮监督重排，有小幅收益，暂留在离线原型

状态：训练、冻结和独立候选评估完成；**没有替换默认排序，没有生成新的 Android 包**。
独立测试的首选由 183/248 增到 186/248，但有 10 条首选退步、字符错误净增 1，
完整句首选总数不变。原定离线汇总门槛通过，产品接入仍暂缓；两种结论分别记录。

## 实现

E12 的实际路径特征已用于训练，不再停留在手工观察分数：

- `prepare_weak_ranker_train.py` 从现有 train 分区按预定规则选择 512 个来源族，
  自动拼音只作弱监督，不宣称人工金标准。没有从 dev/test 答案构造生产词条。
- M19 增加 `sampled` 工作负载：整句无上下文，以及中点后缀加最近两个正确前文字。
  每个来源句两条相关状态；后者是 oracle 前文，不包含前面输入错误的传播。
- `train_candidate_ranker.py` 冻结最多 255 个中文文本各自的 baseline 胜出路径，
  用原始 Float 总分加六个特征增量，不借参考答案重新挑词格路径。
- 特征为词频校准整体、词内 bigram、词边界、字符 LM、外部 bigram、拼写代价。
  unigram mass / normalization anchor 与词频绑定。来源先验、纠错校准、个人证据、
  搜索预算、词库、模型资产均保持。此处没有评估最后混入英文候选后的 UI 名次。
- 每个召回参考文本的 query 与 baseline 前八个其他文本构成偏好对；query 等权，
  query 内各负例等权。未召回 query 不参与损失，但保留在评测分母里。

损失是成对 logistic loss 加 L2 正则；投影批梯度下降带回溯，增量限制在 [-0.75, 1]，
即原特征乘数保持 [0.25, 2]。成对偏好损失借鉴 RankNet 的思路；这里是六维线性模型，
并非论文的神经网络复现，也不借用论文的搜索质量数字。
[Burges 等，Learning to Rank using Gradient Descent](https://www.microsoft.com/en-us/research/wp-content/uploads/2005/08/icml_ranking.pdf)

## 开发选择

1,006 个 query 产生 8,048 对。选择规则为：dev 首选严格增加、前五不降，再按首选、前五、
MRR、较强正则排序。训练最多 300 步，保留未收敛标记，不把到达上限说成收敛。

| 正则 λ | 步数 | 收敛 | dev 首选 /128 | dev 前五 /128 |
|---|---:|---|---:|---:|
| baseline | — | — | 83 | 113 |
| 0.001 | 300 | 否 | 87 | 115 |
| 0.01 | 300 | 否 | 87 | 116 |
| **0.1** | **199** | **是** | **89** | **118** |
| 1 | 19 | 是 | 84 | 115 |

所选增量依次为 `[-0.2346027018, -0.0375677437, 0.0004419125, 0.6215971634,
0.0019135747, 0.0663685513]`，不是部署配置。dev 六条首选改善、零首选损失，但有五条
目标名次退步；整句 dev CER 由 0.0646204 升到 0.0662359，未被总体 CER 下降所掩盖。

### 事后描述性不确定度

用来源句作为重采样单元，整句和中点保持在同一簇；固定 seed 1313，10,000 次 percentile
bootstrap。首选变化 +1.21 个百分点，95% 区间为 **[-3.23, +5.65] 个百分点**；
前五变化 +2.42 个百分点，区间 [+0.40, +4.84]；CER 差区间 [-0.01005, +0.01174]。
这是对已经冻结结果的描述，不是事后重写选择门槛或对全部日常输入的统计保证。

原定门槛是总体首选提高、前五不降、两个模式首选均不降，故 `passedOfflineGate=true`。
**保留这个结果，同时作出独立的产品决定：暂不部署。** 首选小幅净增不足以抵消当前
可见的病句/错词退步，且首选区间跨零。没有把门槛改严后伪称原实验失败，也没有以通过
这个窄门槛替代 Android 输入验收。
