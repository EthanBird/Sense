# D8：大字号、横屏与联想操作时限

日期：2026-10-02。26 键全拼；独立开发工作区。状态：本阶段验收完成，整体质量目标继续进行。

## 本轮解决的问题

F1 加入上下文词级联想后，本轮回到真实输入 UI，而非继续扩张模型。
基线包 SHA-256：`5c82a4e9c986d870ddfa6dca0c2e47a6e30bd48f6af2341956c7b4a9cb2a79f0`。

在 API 37 专用模拟器上复现了三项产品问题：

1. 系统字体放大至 200% 后，“你好”等候选上下笔画被裁切；QWERTY 副标记越出按键，“中/英”越出横向边界。
2. 展开候选按 19sp 测量宽度，却按 17sp 绘制，测量与呈现不一致。
3. 用户将系统交互时限设为 10 秒，联想依旧在 4.5 秒收起。

正常输入、点击及上屏测试在旧包的大字号场景仍可通过，因此单纯“输入结果正确”不足以证明 UI 合格。
本轮增加实际 Canvas 字形回归与截图检查，独立于业务上屏断言。

## 实现

### 同一套字号、几何与宿主窗口高度

- 候选行从固定 45dp 调整为 `45 × max(1, fontScale)`；双行拼音/汉字之间的空间同步调整。
- Surface 与 Keyboard View 共用高度解析，额外补上候选区域增加的高度，不挤占原有四行字母键。
  默认高度：竖屏 358→403dp、横屏 258→303dp（100%→200%）。
- 固定字号 100% 保留原有键盘高度、位置；输入开始、候选出现、联想关闭均不触发字母行上下跳动。
- 展开候选只有一行拼音标题，独立使用 `max(45, 26 × scale)` 的标题高度；
  行高为 `42 + 19 × (scale - 1)`。放大文字，而非等比例放大所有留白。
  200% 的标题/候选行是 52/61dp，在横屏下保留更有效的滚动视口。
- `CandidateScene.textSizePx` 是测量和绘制的唯一字号；展开不再切换到另一套文本大小。
  字号改变才重新测量，连续绘制与滚动继续复用已发布场景和来源索引。
- 大字号主键文字使用真实 Paint 字宽、字体度量及后备字体字形边界适配自身区域。
  竖屏副标记有独立上部区域；不足 48dp 的紧凑按键在放大字号时隐藏副标记，原手势绑定不变。

### 遵循系统交互时限

每次联想闲置计时读取 `AccessibilityManager.getRecommendedTimeoutMillis`，
包括文字、控件和图标标志。普通用户保持 4.5 秒，较长的系统建议得到保留。
异常/较短建议回落到原始时限；使用 Long 保存调度时间。
沿用 D7 的按住/拖动暂停、松手后重计时、编辑会话与显示代次校验。

这采用 [Android AccessibilityManager 官方接口](https://developer.android.com/reference/android/view/accessibility/AccessibilityManager#getRecommendedTimeoutMillis(int,%20int)) 的建议时限，
而非仅根据是否开启无障碍服务切换两套交互路径。

## 红绿回归与证据区分

- **字形实际栅格测试**：旧版参考完整字形为 4,725 个指定墨色像素；
  紧凑候选仅保留 3,517，展开候选因字号变小为 3,654。两个测试均真实失败。
  这些数字只证明该固定字形的裁切/字号差异，不是输入质量分数。
- **超时系统测试**：确认 Android 已接受 10 秒设置，再真正输入“今天”。
  5.5 秒后旧包的联想消失；新版继续显示，并可点击整词进入外部编辑框。
- **配置矩阵**：竖屏/横屏 × 100%/200%，每组包括真实选词及继续输入、展开滚动后的来源词提交、关闭联想后的几何稳定。
- **View 层**：额外覆盖大字号重复绘制不重建场景，保留虚拟候选节点、旧节点拒绝、滚动与触摸所有权回归。
- **记忆与输入回归**：沿用真实外部编辑器的学习、重启、隐私、英文回车、快速确认、冷加载和纠错场景；
  学习数据来自真正选词，不在数据库内预置结果。

### 测试工具本身的错误也保留

早期 runner 只写系统旋转设置，截图仍是竖屏；之后将 UiAutomation 旋转放在 Activity 启动前，
首条用例仍偶发落在竖屏配置。相关失败发生在输入断言之前，归类为回放条件错误，不当作产品通过或产品回归。

最终先启动普通外部编辑器，再对前台窗口请求旋转，等待 RESUMED Activity 的实际配置及屏幕宽高一致；
Activity 重建后更新引用。两轮完整矩阵检查，而非重试单条直到变绿。
每轮保存请求/实际方向、窗口边界、截图、安装包哈希，结束恢复字体、旋转、输入法与时限设置。
所有早期日志继续留存于 `benchmarks/results/d8-raw/`。

## 边界与后续

- 专用 API 37 模拟器，不是实体手机、厂商 ROM 或所有 Android 版本认证。
- 当前系统矩阵覆盖 100%/200%；中间字号还有纯几何和字体度量测试，未声称全部系统字号均实测。
- 未在本轮训练模型或修改 P2C/联想算法；F1 的 Top-8 覆盖下降、真实词边界 Top-3 偏低和启动成本等限制仍然成立。
- 场景缓存测试证明未额外重建，不代表已经测得自然输入帧延迟分布或低端手机能耗。
- 下一阶段继续词句排序、自然输入和系统覆盖；本阶段验收通过不意味着整个输入质量目标完成。
- 尚未 commit、push 或发布 release；不动原目录中 Agent/信道等并行工作。
