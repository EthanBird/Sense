# B3：独立 P2C 评测与 Android 生产入口接线

日期：2026-10-02。开发分支：`codex/input-quality-v2`。本阶段未发布 release。

## 结论

26 键全拼的开发 APK 已默认绑定真实语料训练的字符 1/2/3-gram 模型，权重 **0.5**。
独立 P2C 测试 125 条的首选从 **73 提升到 81**；字符错误 **87 降至 70**。
11 条首选改善、3 条退步，双侧精确 McNemar p=0.05737；不宣称已证明普遍优于基线。
T9 保持原解码器；模型缺失、损坏或读取错误回退原词频路径。个人新词保护继续生效。

本报告的 Android 接线证据为 Robolectric 真实 assets/factory 和 APK 内容校验。
系统 InputMethodService → 外部应用上屏、Android 延迟与生命周期另设 D 阶段验收，不能用这里的 JVM 指标替代。

## 1. 固定数据与先选参后测试

数据协议在查看候选结果之前固定：`benchmarks/corpus/p2c-v1-selection-policy.json`。
从 B1 的开发/测试分片中按 SHA-256 排序选取 64/128 条，分别覆盖 6–9 字、10–16 字。
每个近重复族仅一条；训练/开发前置分片子串及编辑距离 <=1 排除后，不补抽，得到 **63/125**。

`pypinyin 0.55.0` 只负责发音提议。全部 192 条提议在解码前逐条语言审阅，6 条多音字/助词读音修正；
原始书面文字保留，没有依据候选添加同义答案。由本智能体审阅，不冒充独立人工标注团队。
Tatoeba 的旧式表达、异体写法、无上下文同音句仍在集合内，因此本指标是**来源句精确还原**，不是全部可接受表达的评分。

冻结项包括字典、模型、全体 core main Kotlin 源码、样本、选参程序。
`tools/evaluate_p2c.py` 分 dev / freeze-dev / test 三步；首测有启动标记且拒绝覆盖已有证据。
首次测试结束后这 125 条转为已知回归集；后续改进须重新取独立分片才能再次声称新鲜测试。

## 2. 开发集选择

事先定义：首选至少多 3 条、Top-10 至多损失 1 条、总覆盖不下降、CER 不上升。
合格者按首选、CER、Top-3、较小权重排序。

| 模式 | Top-1 /63 | Top-3 | Top-10 | 覆盖 | 字符错误 /600 |
|---|---:|---:|---:|---:|---:|
| 旧词频 + 词库 bigram | 37 | 49 | 56 | 60 | 44 |
| LM 0.25 | 43 | 53 | 59 | 60 | 35 |
| **LM 0.5** | **45** | **55** | 57 | **60** | **29** |
| LM 1.0 | 46 | 51 | 56 | 58 | 30 |
| LM 2.0 | 38 | 44 | 49 | 55 | 45 |

1.0 虽然多一个首选，但覆盖下降，因此按预先规则排除，而非看测试答案决定。

## 3. 首次冻结测试

仅运行基线与已选出的 0.5，不用测试集搜索其他权重。

| 指标 | 基线 | LM 0.5 |
|---|---:|---:|
| Top-1 /125 | 73 (58.4%) | 81 (64.8%) |
| Top-3 | 96 | 102 |
| Top-10 | 115 | 116 |
| 有覆盖 | 118 | 120 |
| MRR | 0.69658 | 0.75063 |
| 字符错误 /1235 | 87 | 70 |
| CER | 7.0445% | 5.6680% |
| 6–9 字首选 /61 | 38 | 39 |
| 10–16 字首选 /64 | 35 | 42 |

三条退步完整保留：

- `停止发牢骚吧` → `停止发牢骚把`，正确句第 2。
- `等你到的时候应该已经散会了` → `等你到的时候应该已经三回了`，正确句第 4。
- `我的广东话比我的普通话好` → `我的广东话比我的普通话号`，正确句第 2。

最终输入的逐步解码入口在 Windows 主机上 p95：34.36 → 43.48 ms。
这不是每一个按键的延迟、不是 Android 帧时间，也不是实时打字性能承诺。

证据：`m12-p2c-dev.json`、`m12-p2c-development-freeze.json`、`m12-p2c-test-start.json`、
`m12-p2c-test.json`、`m12-p2c-conclusion.json`，均在 `benchmarks/results/`。

## 5. 加载、回退与许可交付

- `BundledPinyinLanguageModel` 在已有解码器后台 I/O 执行器加载，固定 3,090,930 字节分配，校验 EOF、SHA-256、格式。
- 状态 READY / DISABLED / MISSING / INVALID / IO_ERROR；关闭流，异常时使用 EMPTY，不把输入文字或异常内容存入模型日志。
- `ProductionPinyinDecoders` 发布同代全拼/T9 二元组。全拼绑定 LM；T9 独立旧路径，两者共享同一用户学习存储。
- 模型 SHA-256：`39ea5d90a38ce2b6f498a0dcc9f4b161ea92168759ebeedd03ce2f3340c45a7d`。
- 模型/语料资产单独遵循 CC BY 2.0 FR；包内署名覆盖 **77,733 原始句、932 位贡献者**。
  逐句 ID→作者 TSV、URL 模板、源快照哈希、训练配置、转换说明与 About 可读通知一并提供。
- 原始训练文本、P2C 测试答案未打包进 APK。

实际 APK 检查发现 aapt 自动解压 `.gz` 并去掉后缀，导致原来源 JSON 指向不存在文件。
先用成品 ZIP 检查复现失败，再把源码索引转为普通 UTF-8 `.tsv`，交由 APK ZIP 压缩，修正所有文件名及哈希。
新增 `audit_packaged_lm.py` 检查成品内部模型/索引文件名、内容哈希、行数、作者数、完整可读署名；
另有自动改名、篡改模型的失败回归。Robolectric 单独不覆盖 aapt 行为，这次明确补上成品层。

修复后 Debug APK：78,639,993 字节，SHA-256
`0032dab4b98b4c9dab06653ffb6c20f6dcc84a73c00850c67c18806b07bfa896`。
TSV 原文 1,359,869 字节，APK 压缩后 286,294 字节。证据：`b3-apk-asset-audit.json`。
