# ADR 0019：v0.4.4 开放 Agent 工具与完整历史

**状态：** Accepted<br>
**日期：** 2026-07-27<br>
**适用版本：** Sense v0.4.4 起<br>
**覆盖关系：** 本 ADR 覆盖 ADR 0015–0018 中阻止产品运行时保留 Agent 数据、
把 Android 已授予能力再次降格为不可用的约束；那些文档继续作为研究与高保障部署
profile 的参考，不再阻断默认产品 profile。

## 1. 背景

Sense Agent 的第一优先级是工具、Skills 与记忆。v0.4.3 的 `SCHEMA_ONLY` checkpoint
证明了一组协议边界，但“默认不保留”和多重产品外授权偏离了产品目标，也使跨 Session
Agent 无法真正成长。

本轮采用开放产品 profile：

- 用户的 Agent 输入、输出、工具过程和结果完整保留；
- Android 系统已经授予的能力就是可执行授权，不再要求一套重复的产品内 Grant；
- 工具是否提供给模型，只能由用户在 Sense 设置页配置；
- Agent 在每次运行中根据任务和工具描述智能选择，不要求用户在键盘上逐次点选工具。

## 2. 决策

### 2.1 完整保留是常开能力

`:brain` 是 Agent 历史的单写者。每个 Run 以稳定本地序号追加保存：

1. 完整请求与编辑器快照；
2. Provider 公开输出与私有输出；
3. 流式预览及状态变化；
4. 工具名称、参数、结果和错误；
5. 最终 Patch、停止、取消、异常和恢复结果。

工具总开关和单项开关都不能停止写入、删除历史或改变历史。已有记录在进程重启后仍可
读取。本版使用确定性词法检索建立 `memory_search`，未来索引、事件图和模型派生投影均是
可替换加速层，不能替代原始记录。

### 2.2 工具开关的唯一写入口是设置页

设置页提供总开关和每项工具开关，默认开启。`:brain` 在每次 Run 开始时读取一次快照：

- 只把已开启工具的 schema 提供给模型；
- 执行前再次按同一快照校验；
- Run 中修改设置只影响下一次 Run，避免执行集合漂移；
- 设置损坏时不覆盖原文件，并在设置页明确显示失败。

模型不能通过猜测隐藏工具名称绕过开关。

### 2.3 v0.4.4 首批工具

| Tool ID | 能力 |
|---|---|
| `web_search` | 搜索公开网络并返回标题、URL 和摘要 |
| `web_fetch` | 读取指定网页的有界正文 |
| `calculator` | 本地确定性计算表达式 |
| `memory_search` | 检索完整保留的本地 Agent 历史 |

工具结果回到同一 Provider 多轮会话，Agent 可以继续调用其他工具，最终仍以唯一
`sense_submit_patch` 结束。`sense_report_progress` 继续负责公开进度，不冒充真实工具。

文件工具按相同原则演进：用户通过 Android Storage Access Framework 选择目录并授予
持久 URI 权限后，Sense 可以直接列出、读取和写入该目录；不再叠加第二套重复授权。
文件效果必须把目标 URI、写入结果与系统异常完整记入历史。

### 2.4 Skills 保持声明式且可组合

现有 `smart_edit`、`answer`、`rewrite`、`continue`、`translate`、`format` 是首批内置
Skills。Skill 决定任务契约，Agent 决定是否调用已启用工具；两者都不拥有历史删除权。
后续 Skill 导入保留原始 bundle、版本和编译快照，以便重放和迁移，但开放性不以禁止
Android 已授权能力为代价。

### 2.5 仍然保留的工程边界

开放不等于让迟到回调或不完整模型文本破坏编辑器。以下既有边界继续有效：

- 上滑锁定只改变交互控制权，不重置 Agent Run；
- 停止后旧 generation 的回调不能落入新 Run；
- 网络正文和流式预览不能直接覆盖输入框；
- 最终写入仍通过结构化 Patch、编辑器 generation、hash/CAS 和写后验证；
- 普通键盘输入热路径不等待网络、Tool 或历史检索。

这些边界保护状态一致性，不构成对用户已授权数据能力的二次限制。

## 3. 发布门禁

v0.4.4 必须同时满足：

1. 设置开关到模型 schema、执行路由的端到端测试；
2. 隐藏工具猜名调用被拒绝；
3. 搜索、网页读取、计算器和记忆检索成功及失败路径测试；
4. 完整 Run 在成功、Provider 错误、用户停止和进程重启后可读取；
5. 工具关闭不停止历史写入；
6. 多工具循环、取消、迟到事件、唯一终止 Patch 回归；
7. 一次真实公网搜索/读取联调，且 CI 使用确定性本地服务器测试避免外网波动；
8. 既有 AI、IME、UI、Core、Lint、APK、签名、权限与性能门禁无回退。
