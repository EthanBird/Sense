## 产品目标

用户输入日常词句时，首选自然、改选方便、学过的词持续可见，快速输入时键盘保持响应。
继续保留九宫格、五笔、英文和 Agent 的既有能力；本专项不扩展 Agent 功能。
开发在 `codex/input-quality-v2` 独立工作区进行，基于远端 `d457eec`，原工作区的未提交改动保持原样。

## 验收层级

1. **确定性正确性**：连续全拼、分段选择、歧义切分、词条记忆、重启恢复、删除反馈、英文 Enter、异步候选版本绑定全部有回归。
2. **输入质量**：分别报告 Top-1/3/10、候选覆盖、MRR、字符错误率和每条失败案例；姓名与无上下文同音句单独归类。
3. **真实输入路径**：逐键执行 `AdaptivePinyinDecoder.decodeProgressively`，覆盖拼音未完成状态；再验证 service 的候选投影、点击和上屏。
4. **性能**：区分首次调用、热身后调用、词库加载、Android 渲染/触摸。主机 JVM 毫秒数不充当手机帧延迟。
5. **数据治理**：来源、许可、快照、SHA-256、清洗规则、训练/开发/冻结评测隔离。评测答案保持在评测目录，不进入生产加权词条。

“通过几十条测试”只算回归基线，不等同于达到主流输入法质量。

### 词频不等于词段平均分

已有 SPLX/3 包约 61 万 canonical 候选。每个词已有 `ln(weight+1)`，无需重造映射表。
令 `Z` 为所有 canonical 发音条目的平滑权重总和，排除 prefix/initials/hybrid 的索引副本；
fallback 来源沿用既有折减。加载时在原有校验循环中累加，不额外建立几十万对象。

搜索使用：

```text
path_score += ln(weight + 1) - ln(Z) + boundary_feature - split_cost
```

beam 在同一输入偏移比较可累加的路径分数，不再让每条路径用不同的词段数作分母。
导出候选时用该查询最佳完整路径的词段数作为**公共仿射变换**，接回现有候选源优先级；
这属于兼容排序校准，不改变无外部上下文时完整路径的相对顺序。
现有字 bigram 仍是词库搭配特征，不是归一化句子条件概率。

外部上下文在 exact 和首段候选限额前参与选择，也用于 beam 存活判断；最终展示评分只加一次。
这是受限 beam 的召回改进，不是对完整上下文 Viterbi 最优性的证明。B2 已加入两字 LM 状态的实验路径。
纠错搜索的廉价词频估计用于分配预算，不称其为忽略 LM 后仍成立的数学上界。
同一原始输入的所有纠正拼写共享分数校准；独立校准每条拼写会偏爱多出的高频音节，
已用 `woshiyigezhongguoern` 在 6/10/64/255 候选限额下的生产词库测试防止回退。

### 缓存层级

跨查询仅缓存 base decoder 的短前缀（1–8 字母），键包含原始拼写、候选限额、前一 Unicode 码点；B2 启用 LM 时再加入两字状态。
上限 32 项且总候选数至多 2048；LRU 淘汰；返回不可变副本，并发 miss 在完整结果产生后发布。
`AdaptivePinyinDecoder` 的用户词、近期反馈、学习和忘记不进入此缓存。
用户词进入词格后，每次前缀探测先读取查询局部的个人词匹配；有匹配的查询绕过静态缓存。
没有个人匹配的查询仍复用基础结果。学习、忘记、降权无需等待缓存失效。
完整句子不放进该缓存，模型/词库变更时创建新的 decoder 实例，缓存随之重建。

E2 另加一次纠错查询内的基础词边缓存，键含记录 ID、音节数和前文字符，上限 128 项／4,096 个候选引用。
只复用词库解码、音节过滤和基础排序；个人词、强制边界及各路径 LM 状态选择不在其中。
它不跨查询保留，与上面的前缀缓存分开，命中时仍响应取消。

### 纠错候选存在两级丢失

E3 诊断将“图中有正确拼写”“进入完整组句”“出现在用户候选”分开统计。大图召回提升不自动等于首屏质量。
拼音图在原有 48 条预算中先按错误类型轮流保留，再沿用近期编辑深度；完整组句仍最多 3／4 条，紧凑已有规范拼写场景仍为 1 条。
全局最佳上下文预估路径优先保留，额外配额只增加多样性。普通单次增删与重复键／模糊音／多次编辑组合区分，避免廉价错误通道挤掉漏键修复。
共享代码也可能影响九宫格调用，因此同步跑 core、M1／M7 回归。未修改词库、字符 LM 权重、错误代价或候选来源先验。

上段描述 E3 时点。E4 在启用 LM、没有完整词条且存在规范组句时，将纠错来源与规范组句的差距从 14 校准到 2；
残差仅存入最终 Candidate.score 一次，不扩大图/beam，不改变完整词条、缺模型和个人新词回退。
局部质量改善和短词退步同时留证，最终验收见 `benchmarks/results/e4-final-acceptance-gate.json`。

评测勘误：此前 M15 的 `joints` 行进入 progressive 前端后会去掉 `'`，是无错句的重复对照，
不是前端强制音节边界覆盖。E4 已显式记录 effectiveQuery；直接 decoder 的边界单测仍有效，前端分隔符生命周期另行处理。
