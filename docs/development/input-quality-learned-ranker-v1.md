# 下一阶段：从句子样本学习排序，而非追加搭配特判

状态：E12 已实现真实路径得分观测；E13 已完成固定特征监督排序原型，尚未进入默认排序。
E38 已验证合格神经教师的离线收益，后续约束见 `input-quality-neural-distillation-v1.md`。
动机：E11 三个结构性规则在开发/独立测试间的表现不一致。
本文件不是输入质量升级或发布验收通过记录。

## 首先实现的纵向切片

1. 从实际候选路径导出有名字、可核对的得分组成，明确词频、词边界、外部搭配、字符 LM、
   来源先验、拼写代价和个人证据；不把已经混合的总分反推成伪特征。
2. 首先做到**只观测、不改变排序**：重复解码的完整候选结果等价，并验证各分项与实际总分的关系。
   观测器只在显式主机评测范围内启用；生产无逐键文本日志。
3. 对真实 train 句子生成候选和正确前缀状态，报告目标召回上限，再做轻量监督重排。
   目标根本没被召回的样本单独统计，不用排名提升掩盖搜索缺口。
4. 保留 baseline 原始分数与特征，让离线试验可以复用同一候选池；阶段初期不同时改搜索预算、模型和词库。

## 数据与学习边界

- 使用已有署名链的 train 分区；dev 只作选择、test 在冻结之后打开。
- 自动拼音标注是弱监督，必须报告多音字、字形变体和错标风险；不要把自动转换说成人工金标准。
- 避免从正确答案构建生产词条、别名或逐句加权表。监督用于少量通用系数，不用于记忆测试句。
- 先比较可解释的线性/成对排序基线，不预设某个模型一定胜出。
- 训练输入、候选输出、特征版本、数据分片、拟合参数和输出权重全部有固定哈希。
- E11 的 31/64 句已经用于模型选择/测试，之后归入已知回归；新版本的独立验收另取未用来源族。

## 搜索与排序的边界

- 先检验冻结候选池上的 oracle 召回和重排收益，再决定是否把学到的特征用于词格 beam。
- 仅重排有收益不等于新的搜索路径已验证；两者分开验收。
- 消融比较至少包含：词频原基线、当前完整 baseline、学习的重排、禁用模型。
- 同音姓名、代词与合理文字变体单列，不把每个目标名次变化都解释为自然语言错误。
- 保留短拼音英文策略、显式分词、退格回滚、prefix 选择、T9 和五笔的现有承诺。
- 个人词的强正反馈、新词回退和忘记操作先保持独立；新通用排序不覆盖明确的个人选择。

## 进入默认包前

必须完成：独立质量对照及所有退步列表、缺失/损坏权重回退、查询/缓存代际隔离、
真实外部输入框与学习重启测试、Android 确认延迟和加载/内存成本对照、资产许可和签名审计。
主机毫秒数不代替手机/模拟器渲染延迟，数据集首选率不代替自然用户体验。

系数方案若未通过，应像 E11 一样保留实验、恢复默认实现，而非放宽门槛后宣称升级完成。

## E12 观测后的调整

- `PinyinScoreDiagnostics` 在得分产生的位置记录 16 个加性分项与独立的来源先验；
  M19 导出实际词边、SPLX 权重/层级、归一化分母与获胜路径索引。保留 Float 原总分，
  Double 分项和 Float 运算顺序的舍入差单列，不作为训练特征。
- 主机观测暂时绕开 prefix candidate cache，不污染缓存；未启用时不创建特征向量/路径表。
  这些是诊断能力，不是新排序算法。个人词格边有覆盖；空个人词库的 M19 导出不代表
  AdaptivePinyinDecoder 外层全部个人反馈已经拆解。
- E11 已知开发集 31 句／270 个 editor 后缀状态中，17 个状态（5 个来源句）有一个
  错误首选路径在全部现有加性分项上支配所有参考文本路径。忽略 Float 舍入、并要求系数
  严格为正时，仅重新缩放现有分项仍会让该错误路径胜出。这不是对所有线性模型的否定，
  也不把代词、合理同音表达等单参考差异一律当作自然输入错误。
- 因此下一步同时设置两个可证伪对照：现有固定特征重排的收益上限，以及 train-only
  更丰富的词/长上下文证据。先做独立数据评估，再选择是否接入搜索，保持姓名/短英文规则。
- unigram mass 与 normalization anchor 属于校准基准，初始拟合保持绑定；不要分别任意学习
  后把长度偏置称为语言理解。使用 baseline 原总分 + 特征增量形式，使零增量精确复原旧排序。
