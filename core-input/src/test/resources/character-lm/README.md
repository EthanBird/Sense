# SCNG/1 interoperability fixture

Authored test text, not downloaded corpus data. Generated by `tools/train_character_lm.py`:

```python
segments = ['我喜欢吃饭'] * 8 + ['你喜欢喝茶'] * 4 + ['𠀀在这里']
model = train_model(segments, min_char_count=1, min_trigram_count=2)
write_model(model, path / 'tiny.scng')
```

`scores.tsv` is calculated by reading the serialized float32 file back with Python, then scoring
the listed Unicode scalar / BOS / EOS / UNK triples. Kotlin checks the same conditional values.
No production model or third-party sentences are bundled in this test directory.
